# HTTP instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method>` (updated to `<HTTP method> <http.route>` for incoming routed requests) | SERVER | `http.request.method`, `http.request.method_original` (if normalization changes the method), `url.scheme`, `server.address`, `server.port`, `network.peer.address`, `network.peer.port`, `network.protocol.version`, `client.address`, `url.path`, `url.query`, `user_agent.original`, `http.response.status_code`, `http.route`, `error.type`, `user_agent.synthetic.type`, configured `http.request.header.<name>`/`http.response.header.<name>`, hook-supplied attributes | Incoming instrumentation can be disabled or ignored by config. `user_agent.synthetic.type` requires `enableSyntheticSourceDetection`; header attributes require `headersToSpanAttributes.server`; error attributes/events are emitted on errors. |
| `<HTTP method>` | CLIENT | `http.request.method`, `http.request.method_original` (if normalization changes the method), `server.address`, `server.port`, `url.full`, `user_agent.original`, `http.response.status_code`, `network.peer.address`, `network.peer.port`, `network.protocol.version`, `error.type`, `user_agent.synthetic.type`, configured `http.request.header.<name>`/`http.response.header.<name>`, hook-supplied attributes | Outgoing instrumentation can be disabled or ignored by config. `user_agent.synthetic.type` requires `enableSyntheticSourceDetection`; header attributes require `headersToSpanAttributes.client`; error attributes/events are emitted on errors. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.duration` | Histogram | s | `http.request.method`, `url.scheme`, `network.protocol.version` (if present), `http.response.status_code`, `http.route`, `error.type` for 5xx/error cases | Recorded when a server span closes; incoming instrumentation can be disabled or ignored by config. |
| `http.client.request.duration` | Histogram | s | `http.request.method`, `server.address`, `server.port`, `http.response.status_code`, `network.protocol.version` (if present), `error.type` for 4xx/5xx/error cases | Recorded when a client span closes; outgoing instrumentation can be disabled or ignored by config. |
