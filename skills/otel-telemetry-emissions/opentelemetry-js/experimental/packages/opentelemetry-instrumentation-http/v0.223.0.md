# HTTP instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method>` | CLIENT | `http.request.method`, `server.address`, `server.port`, `url.full`, `user_agent.original`; conditionally `http.request.method_original`, `user_agent.synthetic.type`, `url.scheme`, `network.protocol.version`, `http.response.status_code`, `error.type`, `network.peer.address`, `network.peer.port` | Client span name may be customized; request/response hook attributes and configured header captures are added when enabled. |
| `<HTTP method>` (updated to `<HTTP method> <http.route>` when a route is available) | SERVER | `http.request.method`, `url.scheme`, `server.address`, `network.peer.address`, `network.peer.port`, `network.protocol.version`, `user_agent.original`; conditionally `url.path`, `url.query`, `client.address`, `server.port`, `http.request.method_original`, `user_agent.synthetic.type`, `http.response.status_code`, `http.route`, `error.type` | Server span name may be customized; request/response hook attributes and configured header captures are added when enabled. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.duration` | Histogram | s | `http.request.method`, `url.scheme`; conditionally `http.response.status_code`, `http.route`, `network.protocol.version`, `error.type` | Recorded when server span closes. |
| `http.client.request.duration` | Histogram | s | `http.request.method`, `server.address`, `server.port`; conditionally `network.protocol.version`, `http.response.status_code`, `error.type` | Recorded when client span closes. |
