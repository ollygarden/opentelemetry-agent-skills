# otelhttp

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{method}` or `{method} {route}` | SERVER | `http.request.method`, `url.scheme`, `server.address`, optionally `server.port`, `http.request.method_original`, `network.peer.address`, `network.peer.port`, `user_agent.original`, `client.address`, `url.path`, `network.protocol.name`, `network.protocol.version`, `http.route`, `http.response.status_code`, `http.request.body.size`, `http.response.body.size` | Default semantic-convention name; custom `WithSpanNameFormatter` can replace it. `ReadEvents` and `WriteEvents` opt-in via `WithMessageEvents` add attribute-less `read`/`write` events (the legacy `http.read_bytes`/`http.wrote_bytes` event attributes are no longer emitted). Public endpoints configured with `WithPublicEndpointFn` create a new root and link a valid remote context. |
| HTTP {method} | CLIENT | `http.request.method`, `http.request.method_original`, `url.full`, `server.address`, optionally `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `error.type` | Created by `Transport`; negotiated response protocol name/version are added when available. Response status and status-derived `error.type` are set on successful responses; transport/read/write errors set `error.type` and error status. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.body.size` | Histogram | By | `http.request.method`, `url.scheme`, `server.address`, optionally `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `http.route`, labeler/custom attributes | Recorded by `Handler` for every accepted request. |
| `http.server.response.body.size` | Histogram | By | Same as `http.server.request.body.size` | - |
| `http.server.request.duration` | Histogram | s | Same as `http.server.request.body.size` | - |
| `http.client.request.body.size` | Histogram | By | `http.request.method`, `server.address`, `url.scheme`, optionally `server.port`, negotiated `network.protocol.name`, negotiated `network.protocol.version`, `http.response.status_code`, `error.type` on transport error, client-labeler/custom attributes | Recorded by `Transport`, including failures. Extra attributes come only from the client labeler (`ContextWithClientLabeler`) or `WithMetricAttributesFn`; server-side `Labeler` attributes such as `http.route` are no longer added. |
| `http.client.request.duration` | Histogram | s | Same as `http.client.request.body.size` | - |
