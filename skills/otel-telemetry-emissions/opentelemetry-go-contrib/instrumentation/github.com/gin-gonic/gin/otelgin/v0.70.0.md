# Gin OpenTelemetry instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{HTTP method} {route}` (or `{HTTP method}` when no route) | SERVER | `server.address`, `http.request.method`, `url.scheme`, `server.port`, `http.request.method.original`, `network.peer.address`, `network.peer.port`, `user_agent.original`, `client.address`, `url.path`, `network.protocol.name`, `network.protocol.version`, `http.route`, `http.response.status_code`, `http.response.body.size`, `error.type` | Request attributes are conditional on request data; `server.port`, `network.peer.port`, `http.response.body.size`, and `http.route` are omitted when unavailable. `network.protocol.name` is omitted for `http`. Response attributes are set after the handler. `error.type` is emitted when Gin has one or more errors; it is the individual error type for one error and `other` for multiple errors. Filters can suppress the span. |
| `gin.renderer.html` | INTERNAL | `go.template` | Emitted by the `HTML` helper. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.body.size` | Histogram (Int64) | By | `http.request.method`, `url.scheme`, `server.address`, `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `http.route`, plus user-supplied metric attributes | Recorded after every non-filtered request. Optional attributes are omitted when unavailable. |
| `http.server.response.body.size` | Histogram (Int64) | By | `http.request.method`, `url.scheme`, `server.address`, `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `http.route`, plus user-supplied metric attributes | Recorded after every non-filtered request. Optional attributes are omitted when unavailable. |
| `http.server.request.duration` | Histogram (Float64) | s | `http.request.method`, `url.scheme`, `server.address`, `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `http.route`, plus user-supplied metric attributes | Recorded after every non-filtered request. Explicit duration buckets are configured. |
