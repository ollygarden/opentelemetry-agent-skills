# otelgrpc

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<package.service>/<method>` (full gRPC method without the leading slash) | Client or server (configurable; defaults to client/server respectively) | New conventions (default): `rpc.method` (fully-qualified method), `rpc.system.name=grpc`, `rpc.response.status_code`; client spans additionally get `server.address` and `server.port` from the remote address, and server spans get them from the local address. Old conventions: `rpc.system=grpc`, `rpc.service`, `rpc.method` (method segment), plus the same response/address attributes. Custom `WithSpanAttributes` are also included. | Spans are gated by `WithFilter`; `OTEL_SEMCONV_STABILITY_OPT_IN=rpc/old` selects old attributes, and `rpc/dup` emits both. Address attributes are emitted only when the corresponding stats address is available. The response status is the canonical gRPC code; server status is Error for Unknown, DeadlineExceeded, Unimplemented, Internal, Unavailable, and DataLoss. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `rpc.client.call.duration` | Histogram | s | `rpc.method`, `rpc.system.name=grpc`, `rpc.response.status_code`, `error.type` (failed RPCs only), `server.address`, `server.port`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Default new RPC semantic conventions; emitted at RPC end. `server.address`/`server.port` are included when the remote address is available. `OTEL_SEMCONV_STABILITY_OPT_IN=rpc/dup` emits this alongside the old metric. Filtered RPCs are not recorded. |
| `rpc.server.call.duration` | Histogram | s | `rpc.method`, `rpc.system.name=grpc`, `rpc.response.status_code`, `error.type` (failed RPCs only); custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Default new RPC semantic conventions; emitted at RPC end. `OTEL_SEMCONV_STABILITY_OPT_IN=rpc/dup` emits this alongside the old metric. Filtered RPCs are not recorded. |
| `rpc.client.duration` | Histogram | ms | `rpc.system=grpc`, `rpc.service`, `rpc.method` (method segment), `rpc.response.status_code`, `server.address`, `server.port`; custom metric attributes | Only with `OTEL_SEMCONV_STABILITY_OPT_IN=rpc/old` or `rpc/dup`; emitted at RPC end. Address attributes are included when the remote address is available. |
| `rpc.server.duration` | Histogram | ms | `rpc.system=grpc`, `rpc.service`, `rpc.method` (method segment), `rpc.response.status_code`; custom metric attributes | Only with `OTEL_SEMCONV_STABILITY_OPT_IN=rpc/old` or `rpc/dup`; emitted at RPC end. |
