## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | See the note below the table. |

`Instrumenter.end` records the `exception` span event only when it receives a throwable; no exception log records are emitted. Span status `ERROR` is set independently of the span event, so an `ERROR` status without a throwable records no span event. The library filter passes a throwable when the filter chain throws or the container reports an async error to its `AsyncListener`; async completion and timeout pass none. Java agent controller and view spans pass the throwable that the handler or view rendering throws. A response with an error status, such as `500`, passes none.
