## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | On by default; see the note below the table. |
| `http.server.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; server spans from the library `SpringWebMvcTelemetry` filter. Off by default; see the note below the table. |
| `exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; Java agent controller and view spans. Off by default; see the note below the table. |

`Instrumenter.end` records exception signals only when it receives a throwable. Span status `ERROR` is set independently of these signals, so an `ERROR` status without a throwable records neither the span event nor a log record. `otel.semconv.exception.signal.preview`, or the declarative `general.semconv_exception.signal.preview`, which takes precedence, selects the signals: `logs` records only the log record, `logs/dup` records both, and unset or any other value records only the span event. Log records are emitted even for unsampled spans. The library filter passes a throwable when the filter chain throws or the container reports an async error to its `AsyncListener`; async completion and timeout pass none. Java agent controller and view spans pass the throwable that the handler or view rendering throws. A response with an error status, such as `500`, passes none.
