# Spring Web MVC

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<method>` or `<method> <http.route>` (for example, `GET /orders`); unknown methods use `HTTP <http.route>`, or `HTTP` when no route matched | SERVER | http.request.method (_OTHER plus http.request.method_original for unknown methods), url.scheme, url.path, url.query, http.response.status_code, error.type, server.address, server.port, client.address, user_agent.original, network.protocol.name, network.protocol.version, network.peer.address, network.peer.port, http.route, http.request.header.*, http.response.header.* | Library SpringWebMvcTelemetry servlet filter only; the Java agent adds no server span here and only updates the route of the servlet server span. Header attributes only when configured for capture |
| `<ClassSimpleName>.<methodName>` (for example, `OrderController.list`); non-HandlerMethod handlers use `handleRequest`, `service`, or `<annotation>` as the method part | INTERNAL | code.namespace, code.function (old code semconv, default) or code.function.name (stable code semconv) | Controller span; disabled by default, enabled by otel.instrumentation.common.experimental.controller-telemetry.enabled. Stable code attributes require OTEL_SEMCONV_STABILITY_OPT_IN=code (code/dup emits both) or otel.instrumentation.common.v3-preview=true |
| `Render <view name>`, `Render <view class simple name>`, or `Render <unknown>` | INTERNAL | spring-webmvc.view.name, spring-webmvc.view.type | Model-and-view span; disabled by default, enabled by otel.instrumentation.common.experimental.view-telemetry.enabled; attributes require otel.instrumentation.spring-webmvc.experimental-span-attributes (default false) |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.duration` | Histogram | s | http.route, http.request.method, http.response.status_code, error.type, network.protocol.name, network.protocol.version, url.scheme | Recorded for completed requests by the library SpringWebMvcTelemetry filter (default on); not emitted by the Java agent module |
| `http.server.active_requests` | UpDownCounter | {requests} | http.request.method, url.scheme | Library filter only; requires experimental HTTP server telemetry, enabled through the internal Experimental helper (default false) |
| `http.server.request.body.size` | Histogram | By | Same as http.server.request.duration | Library filter only; requires experimental HTTP server telemetry (default false); recorded when the body size is known |
| `http.server.response.body.size` | Histogram | By | Same as http.server.request.duration | Library filter only; requires experimental HTTP server telemetry (default false); recorded when the body size is known |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | Recorded on failed spans by default and with `otel.semconv.exception.signal.preview=logs/dup`; not recorded with `logs`. |
| `http.server.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; failed requests in the library SpringWebMvcTelemetry filter; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; failed Java agent controller and view spans; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
