# Spring WebFlux

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{http.request.method}` | CLIENT | `http.request.method`, `url.full`, `server.address`, `server.port`, `http.response.status_code`, `error.type`; optional captured `http.request.header.<key>` and `http.response.header.<key>` | HTTP client span; header attributes are configured with `setCapturedRequestHeaders`/`setCapturedResponseHeaders`. |
| `{http.request.method} {http.route}` (or `{http.request.method} {url.path}` when no route) | SERVER | `http.request.method`, `url.scheme`, `url.path`, `url.query`, `http.route`, `http.response.status_code`, `network.peer.address`, `network.peer.port`, `network.local.address`, `network.local.port`; optional captured request/response headers | HTTP server span. |
| handler method name | INTERNAL | `code.namespace`, `code.function`, `code.filepath`, `code.line.number`, `http.route` | Spring WebFlux controller/handler span; gated by the common `controller-telemetry.enabled` setting (`otel.instrumentation.common.experimental.controller-telemetry.enabled`). |

| Metric name | Type | Unit | Attributes | Notes |
