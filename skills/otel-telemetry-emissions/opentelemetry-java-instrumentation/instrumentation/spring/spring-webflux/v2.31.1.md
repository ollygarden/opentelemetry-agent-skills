## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | On by default; see the note below the table. |
| `http.client.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; WebClient spans. Off by default; see the note below the table. |
| `http.server.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; library server filter spans. Off by default; see the note below the table. |
| `exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; Java agent controller/handler spans. Off by default; see the note below the table. |

`Instrumenter.end` records exception signals only when it receives a throwable. Span status `ERROR` is set independently of these signals, so an `ERROR` status without a throwable records neither the span event nor a log record. `otel.semconv.exception.signal.preview`, or the declarative `general.semconv_exception.signal.preview`, which takes precedence, selects the signals: `logs` records only the log record, `logs/dup` records both, and unset or any other value records only the span event. `SemconvExceptionSignal` reads the selection once at initialization, the declarative key from `GlobalOpenTelemetry`; a non-global `OpenTelemetry` passed to a library builder does not change it. Log records are emitted even for unsampled spans. The instrumentation passes a throwable on an error signal from the WebClient exchange, the library server filter chain, or `DispatcherHandler.handle` (Java agent handler spans), or when `HandlerAdapter.handle` throws. Completion and cancellation pass none, and so does a response with an error status, such as a handler returning `500`.
