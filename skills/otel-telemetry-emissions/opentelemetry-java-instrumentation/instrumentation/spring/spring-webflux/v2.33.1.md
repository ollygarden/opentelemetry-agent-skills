# Spring WebFlux

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{http.request.method}` | CLIENT | `http.request.method`, `url.full`, `server.address`, `server.port`, `http.response.status_code`, `error.type`; optionally captured `http.request.header.<key>` and `http.response.header.<key>` | HTTP client span. Library scope: `io.opentelemetry.spring-webflux-5.3`; agent scope: `io.opentelemetry.spring-webflux-5.0`. Header capture is configured through request/response header selectors. |
| `{http.request.method} {http.route}` (or `{http.request.method} {url.path}` when no route) | SERVER | `http.request.method`, `url.scheme`, `url.path`, `url.query`, `http.route`, `http.response.status_code`, `network.peer.address`, `network.peer.port`, `network.local.address`, `network.local.port`; optionally captured request/response headers | HTTP server span; configured experimental HTTP server telemetry can add experimental attributes. Library scope: `io.opentelemetry.spring-webflux-5.3`. |
| handler method name | INTERNAL | `code.namespace`, `code.function`, `code.filepath`, `code.line.number`, `http.route` | Java agent controller/handler span, scope `io.opentelemetry.spring-webflux-5.0`; gated by `otel.instrumentation.common.experimental.controller-telemetry.enabled` (default disabled). |
