# Spring WebFlux

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{http.request.method}` | CLIENT | `http.request.method`, `url.full`, `server.address`, `server.port`, `http.response.status_code`, `error.type`; optional captured `http.request.header.<key>` and `http.response.header.<key>` | HTTP client span; header attributes are configured with `setCapturedRequestHeaders`/`setCapturedResponseHeaders`. |
| `{http.request.method} {http.route}`; `{http.request.method}` when no route matched (or the pattern is `/**`); unknown methods use `HTTP {http.route}`, or `HTTP` when no route matched | SERVER | `http.request.method` (`_OTHER` plus `http.request.method_original` for unknown methods), `url.scheme`, `url.path`, `url.query`, `http.route`, `http.response.status_code`, `error.type`, `server.address`, `server.port`, `client.address`, `user_agent.original`, `network.peer.address`, `network.peer.port`; optionally captured request/response headers | HTTP server span; configured experimental HTTP server telemetry can add experimental attributes. Library scope: `io.opentelemetry.spring-webflux-5.3`. |
| `{HandlerSimpleClassName}.{methodName}` for annotated handler methods; `{HandlerSimpleClassName}.handle` for other handlers (lambda class names truncated after `$$Lambda`) | INTERNAL | `code.namespace`, `code.function` (old code semconv, default) or `code.function.name` (stable code semconv) | Java agent controller/handler span, scope `io.opentelemetry.spring-webflux-5.0`; gated by `otel.instrumentation.common.experimental.controller-telemetry.enabled` (declarative `controller_telemetry/development`, default false). Stable code attributes require `OTEL_SEMCONV_STABILITY_OPT_IN=code` (`code/dup` emits both) or `otel.instrumentation.common.v3-preview=true`. |

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | Recorded on failed spans by default and with `otel.semconv.exception.signal.preview=logs/dup`; not recorded with `logs`. |
| `http.client.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; failed WebClient requests; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `http.server.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; failed requests in the library server filter; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; failed Java agent controller/handler spans; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
