## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | See the note below the table. |

`Instrumenter.end` records the `exception` span event only when it receives a throwable; no exception log records are emitted. Span status `ERROR` is set independently of the span event, so an `ERROR` status without a throwable records no span event. The instrumentation passes a throwable on an error signal from the WebClient exchange, the library server filter chain, or `DispatcherHandler.handle` (Java agent handler spans), or when `HandlerAdapter.handle` throws. Completion and cancellation pass none, and so does a response with an error status, such as a handler returning `500`.
