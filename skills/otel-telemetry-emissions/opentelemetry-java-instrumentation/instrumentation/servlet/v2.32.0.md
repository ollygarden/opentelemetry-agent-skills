# Servlet

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method> [<route>]` | SERVER | `client.address`, `error.type`, `http.request.method`, `http.request.method_original`, `http.response.status_code`, `http.route` (Servlet 3+/5 only), `network.peer.address`, `network.peer.port` (Servlet 3+/5 only), `network.protocol.name`, `network.protocol.version`, `server.address`, `server.port`, `url.path`, `url.query`, `url.scheme`, `user_agent.original`; optionally `http.request.header.<key>`, `http.response.header.<key>`, `servlet.request.parameter.<name>` (string array), `servlet.timeout`, `user.name`/`enduser.id`, `http.request.body.size`, `http.response.body.size` | `servlet.request.parameter.<name>` uses `otel.instrumentation.servlet.experimental.request-parameters.included`/`.excluded` selectors (the legacy capture property is deprecated); captured header attributes use request/response `IncludeExclude` selectors in the Servlet 3.0 and 5.0 library builders; `servlet.timeout` requires `otel.instrumentation.servlet.experimental-span-attributes`; `user.name` (semconv v3 preview) or `enduser.id` requires agent user-name capture; body-size attributes require experimental HTTP server telemetry. |
| `HttpServletResponse.sendRedirect` | INTERNAL | `code.function`, `code.namespace` | Java agent response instrumentation only; emitted when called inside an active servlet server span. |
| `HttpServletResponse.sendError` | INTERNAL | `code.function`, `code.namespace` | Java agent response instrumentation only; emitted when called inside an active servlet server span. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.duration` | Histogram | `s` | `error.type`, `http.request.method`, `http.response.status_code`, `http.route` (Servlet 3+/5 only), `network.protocol.name`, `network.protocol.version`, `server.address`, `server.port`, `url.scheme` | - |
| `http.server.active_requests` | UpDownCounter | `{requests}` | HTTP server request attributes available at start, including `http.request.method`, `server.address`, `server.port`, `url.scheme`, `network.protocol.name`, `network.protocol.version` | Requires experimental HTTP server telemetry (`http.server.emit-experimental-telemetry`). |
| `http.server.request.body.size` | Histogram | `By` | HTTP server request attributes | Requires experimental HTTP server telemetry; recorded only when a request body size is available. |
| `http.server.response.body.size` | Histogram | `By` | HTTP server response attributes | Requires experimental HTTP server telemetry; recorded only when a response body size is available. |
