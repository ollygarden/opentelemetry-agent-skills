# Servlet

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| Servlet 3.0/5.0: `<HTTP method> [<route>]`; Servlet 2.2: `<HTTP method> <context path><servlet path>` when a servlet path is present, else `<HTTP method>`; unknown methods use `HTTP` | SERVER | `client.address`, `error.type`, `http.request.method`, `http.request.method_original`, `http.response.status_code`, `http.route` (Servlet 3+/5 only), `network.peer.address`, `network.peer.port` (Servlet 3+/5 only), `network.protocol.name`, `network.protocol.version`, `server.address`, `server.port`, `url.path`, `url.query`, `url.scheme`, `user_agent.original`; optionally `http.request.header.<key>`, `http.response.header.<key>`, `servlet.request.parameter.<name>` (string array), `servlet.timeout`, `user.name`/`enduser.id`, `http.request.body.size`, `http.response.body.size` | Request parameters use `otel.instrumentation.servlet.experimental.request-parameters.included`/`.excluded` selectors (empty by default); Servlet 2.2 also accepts `otel.instrumentation.servlet.experimental.capture-request-parameters` as an include-only alias. Captured request/response header attributes require non-empty header capture configuration; the Java agent reads the common HTTP server header settings, and the Servlet 3.0/5.0 library builders expose header selectors (empty by default). `servlet.timeout` requires `otel.instrumentation.servlet.experimental-span-attributes` (default false); `user.name` (semconv v3 preview) or `enduser.id` requires Java agent user-name capture; body-size attributes require experimental HTTP server telemetry. |
| `HttpServletResponse.sendRedirect` | INTERNAL | `code.function`, `code.namespace` | Java agent response instrumentation only; emitted when called inside an active servlet server span. |
| `HttpServletResponse.sendError` | INTERNAL | `code.function`, `code.namespace` | Java agent response instrumentation only; emitted when called inside an active servlet server span. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.request.duration` | Histogram | `s` | `error.type`, `http.request.method`, `http.response.status_code`, `http.route` (Servlet 3+/5 only), `network.protocol.name`, `network.protocol.version`, `url.scheme` | Attribute advice; SDK views can change the retained set. |
| `http.server.active_requests` | UpDownCounter | `{requests}` | `http.request.method`, `url.scheme` | Requires experimental HTTP server telemetry (`otel.instrumentation.http.server.emit-experimental-telemetry`, default false for the Java agent; opt-in builder setting for the library). |
| `http.server.request.body.size` | Histogram | `By` | HTTP server request attributes | Requires experimental HTTP server telemetry; recorded only when a request body size is available. |
| `http.server.response.body.size` | Histogram | `By` | HTTP server response attributes | Requires experimental HTTP server telemetry; recorded only when a response body size is available. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | Recorded on failed spans by default and with `otel.semconv.exception.signal.preview=logs/dup`; not recorded with `logs`. |
| `http.server.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; failed HTTP server requests; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; failed `HttpServletResponse.sendRedirect` and `HttpServletResponse.sendError` spans; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
