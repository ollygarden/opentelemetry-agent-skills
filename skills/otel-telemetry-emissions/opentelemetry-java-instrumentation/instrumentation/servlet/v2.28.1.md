## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | See the note below the table. |

`Instrumenter.end` records the `exception` span event only when it receives a throwable; no exception log records are emitted. Span status `ERROR` is set independently of the span event, so an `ERROR` status without a throwable records no span event. The instrumentation passes a throwable when a servlet, a filter, or an async dispatch throws, when the container reports an async error to the `AsyncListener`, or when `sendRedirect` or `sendError` throws. A response with an error status, such as `500` set through `sendError`, passes none, and neither does an async timeout without an earlier exception.
