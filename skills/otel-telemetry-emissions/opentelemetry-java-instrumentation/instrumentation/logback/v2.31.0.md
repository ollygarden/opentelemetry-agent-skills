# Logback

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| Logback event message | thread.name, thread.id (experimental attributes; thread.id agent only); code.filepath, code.namespace, code.function, code.lineno (old code semconv) or code.file.path, code.function.name, code.line.number (stable code semconv); logback.marker; log.body.template, log.body.parameters; selected MDC, logger-context, SLF4J key-value pair, Logstash marker and structured-argument attributes | thread.* gated by agent experimental_log_attributes/development=false or library appender captureExperimentalAttributes=false (the library appender emits thread.name only); code attributes gated by capture_code_attributes/development=false; logback.marker gated by capture_marker_attribute/development=false; template and arguments gated by capture_template/development=false and capture_arguments/development=false; dynamic attribute selectors default to none; Logstash attributes depend on Logstash Logback Encoder support; code attributes use old or stable keys according to semconv stability configuration; event name otel.event.name is read from MDC, SLF4J key-value pairs, Logstash markers and supported structured arguments; trace/span context is current Context; Logback MDC agent adds baggage.* entries to context only when logback-mdc add_baggage=true (default false), and library appender adds baggage.* to MDC only when addBaggage=true |
