# Logback

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| Logback event message | thread.name, thread.id (experimental attributes; thread.id agent only); code.filepath, code.namespace, code.function, code.lineno (old code semconv) or code.file.path, code.function.name, code.line.number (stable code semconv); logback.marker; log.body.template, log.body.parameters; exception.type, exception.message, exception.stacktrace (only when the event carries a ThrowableProxy throwable); selected MDC, logger-context, SLF4J key-value pair, Logstash marker and structured-argument attributes | thread.*, code, logback.marker, template and argument attributes are each emitted only when their setting is true (all default false): agent experimental_log_attributes/development, capture_code_attributes/development, capture_marker_attribute/development, capture_template/development and capture_arguments/development, or library appender captureExperimentalAttributes, captureCodeAttributes, captureMarkerAttribute, captureTemplate and captureArguments; the library appender emits thread.name only; template and arguments also require a non-empty argument array; MDC attributes require agent capture_mdc_attributes/development or library captureMdcAttributes, a comma-separated list of keys or * for all (default none); logger-context, SLF4J key-value pair, Logstash marker and structured-argument attributes require agent capture_logger_context_attributes/development, capture_key_value_pair_attributes/development, capture_logstash_marker_attributes/development and capture_logstash_structured_arguments/development, or library captureLoggerContext, captureKeyValuePairAttributes, captureLogstashMarkerAttributes and captureLogstashStructuredArguments (all default false); Logstash attributes depend on Logstash Logback Encoder support; code attributes use old or stable keys according to semconv stability configuration, and both with `otel.semconv-stability.opt-in=code/dup` unless `otel.instrumentation.common.v3-preview=true`; event name otel.event.name is read from MDC, SLF4J key-value pairs, Logstash markers and supported structured arguments; trace/span context is current Context; Logback MDC agent adds baggage.* entries to the event MDC map only when logback-mdc add_baggage=true (default false), and library appender adds baggage.* to MDC only when addBaggage=true; neither adds baggage when the event MDC already contains the configured trace ID key |
