# Logback

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| Logback event message | thread.name, thread.id (experimental attributes; thread.id agent only); code.filepath, code.namespace, code.function, code.lineno (old code semconv) or code.file.path, code.function.name, code.line.number (stable code semconv); logback.marker; log.body.template, log.body.parameters; exception.type, exception.message, exception.stacktrace (only when the event carries a ThrowableProxy throwable); selected MDC, logger-context, SLF4J key-value pair, Logstash marker and structured-argument attributes | thread.*, code, logback.marker, template and argument attributes are each emitted only when their setting is true (all default false): agent experimental_log_attributes/development, capture_code_attributes/development, capture_marker_attribute/development, capture_template/development and capture_arguments/development, or library appender captureExperimentalAttributes, captureCodeAttributes, captureMarkerAttribute, captureTemplate and captureArguments; the library appender emits thread.name only; template and arguments also require a non-empty argument array; dynamic attribute selectors default to none, except that with otel.instrumentation.common.v3-preview=true the agent SLF4J key-value pair, Logstash marker and structured-argument selectors default to all; Logstash attributes depend on Logstash Logback Encoder support; code attributes use old or stable keys according to semconv stability configuration; event name otel.event.name is read from MDC, SLF4J key-value pairs, Logstash markers and supported structured arguments; trace/span context is current Context; Logback MDC agent adds baggage.* entries to context only when logback-mdc add_baggage=true (default false), and library appender adds baggage.* to MDC only when addBaggage=true |
