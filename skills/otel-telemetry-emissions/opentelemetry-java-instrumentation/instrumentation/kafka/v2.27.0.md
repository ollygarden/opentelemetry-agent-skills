# Kafka instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `publish {messaging.destination.name}` | PRODUCER | `messaging.system`, `messaging.destination.name`, `messaging.operation` (`publish`), `messaging.client_id`, `messaging.destination.partition.id` (on completion), `messaging.kafka.offset` / `messaging.kafka.message.offset` (on completion), `messaging.kafka.message.key`, `messaging.kafka.message.tombstone`, captured `messaging.header.*` | Offset uses stable/old messaging semantic-convention gates respectively; header attributes are opt-in via `messaging.capture-headers`. |
| `receive {messaging.destination.name}` | CONSUMER | `messaging.system`, `messaging.destination.name`, `messaging.operation` (`receive`), `messaging.client_id`, `messaging.batch.message_count`, `messaging.kafka.consumer.group`, captured `messaging.header.*` | Receive telemetry is disabled by default; enable with `otel.instrumentation.messaging.experimental.receive-telemetry.enabled`. |
| `process {messaging.destination.name}` | CONSUMER | `messaging.system`, `messaging.destination.name`, `messaging.operation` (`process`), `messaging.client_id`, `messaging.destination.partition.id`, `messaging.message.body.size`, `messaging.kafka.consumer.group`, `messaging.kafka.offset` / `messaging.kafka.message.offset`, `messaging.kafka.message.key`, `messaging.kafka.message.tombstone`, `kafka.record.queue_time_ms`, captured `messaging.header.*` | `kafka.record.queue_time_ms` and `messaging.kafka.bootstrap.servers` are gated by `otel.instrumentation.kafka.experimental-span-attributes`; queue time is only present when the record has a timestamp. Offset uses stable/old messaging semantic-convention gates; headers are opt-in. Kafka Connect emits a batch process span with `messaging.batch.message_count` and links to each record; Kafka Streams emits the process span for each processed source record. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `kafka.consumer.<kafka-metric-name>` | Observable gauge, or observable counter for Kafka cumulative sum/count measurables | `{kafka metric unit}` | Kafka metric tags | Dynamically bridges measurable Kafka client metrics whose group contains `consumer`; emitted only when `OpenTelemetryMetricsReporter` is configured through `KafkaTelemetry`. Names replace `-` with `_`. |
| `kafka.producer.<kafka-metric-name>` | Observable gauge, or observable counter for Kafka cumulative sum/count measurables | `{kafka metric unit}` | Kafka metric tags | Same dynamic reporter behavior for metric groups containing `producer`; names replace `-` with `_`. |
