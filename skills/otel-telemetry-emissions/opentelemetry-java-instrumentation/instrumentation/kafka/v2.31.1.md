## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | On by default; see the note below the table. |
| `messaging.send.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; send spans. Off by default; see the note below the table. |
| `messaging.receive.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; receive spans. Off by default; see the note below the table. |
| `messaging.process.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; process spans, including Kafka Connect and Kafka Streams. Each log uses the scope of the instrumenter that emitted it. Off by default; see the note below the table. |

`Instrumenter.end` records exception signals only when it receives a throwable. Span status `ERROR` is set independently of these signals, so an `ERROR` status without a throwable records neither the span event nor a log record. `otel.semconv.exception.signal.preview`, or the declarative `general.semconv_exception.signal.preview`, which takes precedence, selects the signals: `logs` records only the log record, `logs/dup` records both, and unset or any other value records only the span event. `SemconvExceptionSignal` reads the selection once at initialization, the declarative key from `GlobalOpenTelemetry`; a non-global `OpenTelemetry` passed to a library builder does not change it. Log records are emitted even for unsampled spans. The instrumentation passes a throwable to a send span when `send` throws or its callback reports an exception, and to a Kafka Streams or Kafka Connect process span when `StreamTask.process` or `SinkTask.put` throws; producer-interceptor send spans get none. It passes none to receive spans or kafka-clients process spans: a failed `poll()` creates no receive span, and an exception thrown while processing an iterated record is not passed to its process span.
