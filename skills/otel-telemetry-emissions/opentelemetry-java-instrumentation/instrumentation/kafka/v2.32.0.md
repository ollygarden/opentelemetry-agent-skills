# Kafka instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `send {messaging.destination.name}` (stable); `{messaging.destination.name} publish` (old) | PRODUCER | `messaging.system`, `messaging.destination.name`, stable `messaging.operation.name` (`send`), `messaging.operation.type` (`send`), `messaging.client.id`; or old `messaging.operation` (`publish`), `messaging.client_id`; `messaging.destination.partition.id` (on completion), `messaging.kafka.offset` / `messaging.kafka.message.offset` (stable/old), `messaging.kafka.message.key`, `messaging.kafka.message.tombstone`, `error.type` (stable), captured `messaging.header.*` | Header attributes use `otel.instrumentation.messaging.experimental.headers.included`/`.excluded` selectors; legacy `otel.instrumentation.messaging.experimental.capture-headers` is deprecated. |
| `poll {messaging.destination.name}` (stable); `{messaging.destination.name} receive` (old) | CONSUMER | `messaging.system`, `messaging.destination.name`, stable `messaging.operation.name` (`poll`), `messaging.operation.type` (`receive`), `messaging.client.id`, `messaging.consumer.group.name`; or old `messaging.operation` (`receive`), `messaging.client_id`, `messaging.kafka.consumer.group`; `messaging.batch.message_count`, `error.type` (stable), captured `messaging.header.*` | Receive telemetry disabled by default; enable with `otel.instrumentation.messaging.experimental.receive-telemetry.enabled`. |
| `process {messaging.destination.name}` (stable); `{messaging.destination.name} process` (old) | CONSUMER | `messaging.system`, `messaging.destination.name`, stable `messaging.operation.name`/`messaging.operation.type` (`process`), `messaging.client.id`, `messaging.consumer.group.name`; or old `messaging.operation` (`process`), `messaging.client_id`, `messaging.kafka.consumer.group`; `messaging.destination.partition.id`, old `messaging.message.body.size`, `messaging.kafka.offset` / `messaging.kafka.message.offset` (stable/old), `messaging.kafka.message.key`, `messaging.kafka.message.tombstone`, `error.type` (stable), `kafka.record.queue_time_ms`, captured `messaging.header.*` | `kafka.record.queue_time_ms` and `messaging.kafka.bootstrap.servers` gated by `otel.instrumentation.kafka.experimental-span-attributes`; queue time requires record timestamp. Kafka Connect emits batch process span with `messaging.batch.message_count` and per-record links; Kafka Streams emits a process span per processed source record. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `messaging.client.operation.duration` | Histogram | s | `messaging.system`, `messaging.operation.name`, `messaging.operation.type`, `messaging.destination.name`, `messaging.consumer.group.name`, `messaging.destination.partition.id`, `error.type` | Stable messaging conventions for send and receive/poll; interceptor-only instrumentation omits it. |
| `messaging.client.sent.messages` | Counter | `{message}` | `messaging.system`, `messaging.operation.name`, `messaging.destination.name`, `messaging.destination.partition.id`, `error.type` | Stable conventions; counts attempted producer sends. |
| `messaging.client.consumed.messages` | Counter | `{message}` | `messaging.system`, `messaging.operation.name`, `messaging.destination.name`, `messaging.consumer.group.name`, `messaging.destination.partition.id`, `error.type` | Recorded once by receive/poll or process when receive telemetry is suppressed. |
| `messaging.process.duration` | Histogram | s | `messaging.system`, `messaging.operation.name`, `messaging.destination.name`, `messaging.consumer.group.name`, `messaging.destination.partition.id`, `error.type` | Stable messaging conventions for processing duration. |
| `kafka.consumer.<kafka-metric-name>` | Observable gauge or observable counter for cumulative sum/count measurables | `{kafka metric unit}` | Kafka metric tags | Dynamically bridges measurable Kafka client metrics for groups containing `consumer`; requires `OpenTelemetryMetricsReporter` configured through `KafkaTelemetry`; names replace `-` with `_`. |
| `kafka.producer.<kafka-metric-name>` | Observable gauge or observable counter for cumulative sum/count measurables | `{kafka metric unit}` | Kafka metric tags | Same dynamic reporter behavior for groups containing `producer`; names replace `-` with `_`. |
