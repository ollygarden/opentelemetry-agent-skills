## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | See the note below the table. |

`Instrumenter.end` records the `exception` span event only when it receives a throwable; no exception log records are emitted. Span status `ERROR` is set independently of the span event, so an `ERROR` status without a throwable records no span event. The instrumentation passes a throwable when `send` or `sendAsync` throws, or when the `sendAsync` future completes exceptionally. A response with an error status, such as `404` or `500`, passes none.
