# Java HTTP Client

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| HTTP request method (for example, `GET`; `_OTHER` for unrecognized methods) | CLIENT | `http.request.method`, `http.request.method_original` (unknown methods), `url.full`, `server.address`, `server.port`, `http.response.status_code`, `error.type`, `network.protocol.version`, `http.request.header.<key>` (configured), `http.response.header.<key>` (configured), `http.request.resend_count` (retries/resends) | `network.protocol.version` is `1.1` or `2`; captured headers require `http.client.capture-request-headers`/`http.client.capture-response-headers`; `url.template`, `http.request.body.size`, and `http.response.body.size` require `http.client.emit-experimental-telemetry`; exception span events are controlled by `otel.semconv.exception.signal.preview` |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.client.request.duration` | Histogram | s | `http.request.method`, `http.response.status_code`, `error.type`, `network.protocol.version`, `server.address`, `server.port`, `url.template` (when present) | `url.template` is emitted only with `http.client.emit-experimental-telemetry` |
| `http.client.request.body.size` | Histogram | By | `http.request.method`, `http.response.status_code`, `error.type`, `network.protocol.version`, `server.address`, `server.port`, `url.template` | Experimental; requires `http.client.emit-experimental-telemetry`; recorded when request `Content-Length` is numeric |
| `http.client.response.body.size` | Histogram | By | `http.request.method`, `http.response.status_code`, `error.type`, `network.protocol.version`, `server.address`, `server.port`, `url.template` | Experimental; requires `http.client.emit-experimental-telemetry`; recorded when response `Content-Length` is numeric |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `http.client.request.exception` | `exception.type`, `exception.message`, `exception.stacktrace` | Exception log with WARN severity; emitted only when `otel.semconv.exception.signal.preview` is `logs` or `logs/dup` |
