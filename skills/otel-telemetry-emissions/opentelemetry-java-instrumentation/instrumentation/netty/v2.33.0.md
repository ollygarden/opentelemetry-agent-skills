# Netty instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| HTTP client span (HTTP method + target, per HTTP semantic conventions) | CLIENT | HTTP client request/response attributes, network peer/server attributes, error attributes | Netty 3.8/4.0/4.1 HTTP client instrumentation; standard HTTP instrumenter |
| HTTP server span (HTTP method + target, per HTTP semantic conventions) | SERVER | HTTP server request/response attributes, network client attributes, error attributes | Netty 4.1 server instrumentation; standard HTTP instrumenter |
| connect | CLIENT (default error-only) or INTERNAL (enabled) | network peer/server address and port, HTTP client attributes and error attributes in error-only mode | Netty 4.0/4.1 connection instrumentation; gated by java.netty.connection_telemetry.enabled (default false selects error-only, true enables all connection spans); Java agent scope is io.opentelemetry.netty-4.0 or io.opentelemetry.netty-4.1 |
| ssl.handshake | CLIENT (default error-only) or INTERNAL (enabled) | network peer address and port, error attributes | Netty 4.0/4.1 TLS handshake instrumentation; gated by java.netty.ssl_telemetry.enabled (default false selects error-only, true enables all handshake spans); Java agent scope is io.opentelemetry.netty-4.0 or io.opentelemetry.netty-4.1 |
