# Netty instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| HTTP request method (`HTTP` for unknown methods); `{method} {url.template}` when experimental HTTP client telemetry is enabled and a URL template is available | CLIENT | HTTP client request/response attributes, network peer/server attributes, `error.type` | Netty 3.8/4.0/4.1 Java agent client instrumentation and Netty 4.1 library `NettyClientTelemetry`; standard HTTP client instrumenter. |
| HTTP request method (`HTTP` for unknown methods); `{method} {http.route}` when a route is set | SERVER | HTTP server request/response attributes, network client attributes, `error.type` | Netty 3.8/4.0/4.1 Java agent server instrumentation and Netty 4.1 library `NettyServerTelemetry`; standard HTTP server instrumenter. |
| `CONNECT` | CLIENT (error-only) or INTERNAL (enabled) | Error-only: HTTP client attributes including `server.address`, `server.port`, `error.type`; enabled: network peer attributes, `server.address`, `server.port`; service peer attributes when peer mapping matches | Netty 4.0/4.1 Java agent: `otel.instrumentation.netty.connection-telemetry.enabled` (`java.netty.connection_telemetry.enabled`, default false) emits a CLIENT span only for failed connections; true emits an INTERNAL span for every connection. Netty 3.8 always emits a CLIENT span for failed connections. Not created by the Netty 4.1 library. |
| `SSL handshake` | CLIENT (error-only) or INTERNAL (enabled) | `network.transport`, `network.peer.address`, `network.peer.port` | Netty 4.0/4.1 Java agent: `otel.instrumentation.netty.ssl-telemetry.enabled` (`java.netty.ssl_telemetry.enabled`, default false) emits a CLIENT span only for failed handshakes; true emits an INTERNAL span for every handshake. Not created by the Netty 4.1 library. |
| `http.response.status_code.101.upgrade` (span event) | — | `network.protocol.from`, `network.protocol.to` | Netty 4.1 only; added on `101 Switching Protocols` responses when experimental HTTP client or server telemetry is enabled (default false). |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.client.request.duration` | Histogram | s | `http.request.method`, `http.response.status_code`, `error.type`, `network.protocol.name`, `network.protocol.version`, `server.address`, `server.port`; `url.template` with experimental telemetry | Registered by every HTTP client instrumenter (Netty 3.8/4.0/4.1 agent, 4.1 library). Not recorded for `CONNECT` or `SSL handshake` spans. |
| `http.client.request.body.size` | Histogram | By | Same as `http.client.request.duration` | Requires `otel.instrumentation.http.client.emit-experimental-telemetry` (default false; library opt-in through the internal `Experimental` helper); recorded only when the request `Content-Length` header is numeric. |
| `http.client.response.body.size` | Histogram | By | Same as `http.client.request.duration` | Requires experimental HTTP client telemetry (default false); recorded only when the response `Content-Length` header is numeric. |
| `http.server.request.duration` | Histogram | s | `http.route`, `http.request.method`, `http.response.status_code`, `error.type`, `network.protocol.name`, `network.protocol.version`, `url.scheme` | Registered by every HTTP server instrumenter (Netty 3.8/4.0/4.1 agent, 4.1 library); emitted by default. |
| `http.server.active_requests` | UpDownCounter | `{requests}` | `http.request.method`, `url.scheme` | Requires `otel.instrumentation.http.server.emit-experimental-telemetry` (default false; library opt-in through the internal `Experimental` helper). |
| `http.server.request.body.size` | Histogram | By | Same as `http.server.request.duration` | Requires experimental HTTP server telemetry (default false); recorded only when the request `Content-Length` header is numeric. |
| `http.server.response.body.size` | Histogram | By | Same as `http.server.request.duration` | Requires experimental HTTP server telemetry (default false); recorded only when the response `Content-Length` header is numeric. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` | Recorded on failed spans by default and with `otel.semconv.exception.signal.preview=logs/dup`; not recorded with `logs`. |
| `http.client.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; failed HTTP client requests and error-only `CONNECT` spans; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `http.server.request.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; failed HTTP server requests; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; failed fully enabled `CONNECT` spans and `SSL handshake` spans; only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |

A span fails when it ends with a throwable, such as a channel exception or a connection or SSL handshake failure. An HTTP error status alone, such as a `500` response, records neither the span event nor a log record.
