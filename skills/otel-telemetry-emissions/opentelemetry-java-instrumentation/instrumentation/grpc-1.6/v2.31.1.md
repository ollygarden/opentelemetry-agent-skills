# gRPC

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{service}/{method}` | CLIENT | `rpc.system.name` / legacy `rpc.system`; `rpc.service`; `rpc.method`; `server.address`; `server.port`; network attributes; `rpc.response.status_code` / legacy `rpc.grpc.status_code`; configured request metadata attributes | Stable and legacy RPC semantic conventions are selected by semconv stability configuration; metadata capture requires client request-metadata selector. |
| `{service}/{method}` | SERVER | `rpc.system.name` / legacy `rpc.system`; `rpc.service`; `rpc.method`; `server.address`; `server.port`; network attributes; `rpc.response.status_code` / legacy `rpc.grpc.status_code`; configured request metadata attributes | Stable and legacy RPC semantic conventions are selected by semconv stability configuration; metadata capture requires server request-metadata selector. |
| `message` | — | `message.type` (`SENT`/`RECEIVED`), `message.id` | Event controlled by `otel.instrumentation.grpc.emit-message-events` (default true). |
| `{service}/{method}` | SERVER span attributes | `grpc.canceled`, `grpc.received.message_count`, `grpc.sent.message_count` | Experimental attributes require `otel.instrumentation.grpc.experimental-span-attributes`; canceled attribute only on cancellation. |
| `{service}/{method}` | CLIENT span attributes | `grpc.received.message_count`, `grpc.sent.message_count` | Experimental attributes require `otel.instrumentation.grpc.experimental-span-attributes`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `rpc.client.duration` | Histogram | ms | `rpc.system`, `rpc.service`, `rpc.method`, `rpc.grpc.status_code`, `network.type`, `network.transport`, `server.address`, `server.port` | Old RPC semconv: emitted by default and with `rpc/dup`; not emitted with `rpc`. |
| `rpc.server.duration` | Histogram | ms | `rpc.system`, `rpc.service`, `rpc.method`, `rpc.grpc.status_code`, `network.type`, `network.transport`, `server.address`, `server.port` | Old RPC semconv: emitted by default and with `rpc/dup`; not emitted with `rpc`. |
| `rpc.client.call.duration` | Histogram | s | `rpc.system.name`, `rpc.method`, `rpc.response.status_code`, `server.address`, `server.port` | Only when RPC v1 semconv is selected with `rpc` or `rpc/dup` (default off). |
| `rpc.server.call.duration` | Histogram | s | `rpc.system.name`, `rpc.method`, `rpc.response.status_code`, `server.address`, `server.port` | Only when RPC v1 semconv is selected with `rpc` or `rpc/dup` (default off). |
| `rpc.client.request.size` | Histogram | By | Old RPC attributes (as `rpc.client.duration`) | Old RPC semconv only (default or `rpc/dup`); the builder always installs size extraction, and a value is recorded only when the message is a protobuf `MessageLite` (serialized size). |
| `rpc.client.response.size` | Histogram | By | Old RPC attributes (as `rpc.client.duration`) | Old RPC semconv only (default or `rpc/dup`); the builder always installs size extraction, and a value is recorded only when the message is a protobuf `MessageLite` (serialized size). |
| `rpc.server.request.size` | Histogram | By | Old RPC attributes (as `rpc.server.duration`) | Old RPC semconv only (default or `rpc/dup`); the builder always installs size extraction, and a value is recorded only when the message is a protobuf `MessageLite` (serialized size). |
| `rpc.server.response.size` | Histogram | By | Old RPC attributes (as `rpc.server.duration`) | Old RPC semconv only (default or `rpc/dup`); the builder always installs size extraction, and a value is recorded only when the message is a protobuf `MessageLite` (serialized size). |

RPC semconv selection: explicit declarative `general.rpc.semconv` config takes precedence over flags; `version: 0` selects old only, and `version: 1` with `experimental: true` selects v1 (`dual_emit: true` selects both). Otherwise `rpc` and `rpc/dup` are read from `otel.semconv-stability.preview`, and also from `otel.semconv-stability.opt-in` unless `otel.instrumentation.common.v3-preview=true`.

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` (when available) | Recorded on failed calls, by default and with `otel.semconv.exception.signal.preview=logs/dup`; not recorded with `logs`. |
| `rpc.client.call.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; emitted on failed client calls only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |
| `rpc.server.call.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; emitted on failed server calls only when `otel.semconv.exception.signal.preview=logs` or `logs/dup` (default off). |

A call fails when it ends with a throwable: one thrown by the call or listener, or the cause of the closing `Status`. A non-OK `Status` without a cause records neither the span event nor the log record.
