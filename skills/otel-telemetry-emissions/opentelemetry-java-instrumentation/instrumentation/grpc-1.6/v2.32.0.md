# gRPC

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{service}/{method}` | CLIENT | `rpc.system.name` / legacy `rpc.system`; `rpc.service`; `rpc.method`; `server.address`; `server.port`; network attributes; `rpc.response.status_code` / legacy `rpc.grpc.status_code`; configured request metadata attributes | Stable and legacy RPC semantic conventions are selected by semconv stability configuration; metadata capture requires client request-metadata selector. |
| `{service}/{method}` | SERVER | `rpc.system.name` / legacy `rpc.system`; `rpc.service`; `rpc.method`; `server.address`; `server.port`; network attributes; `rpc.response.status_code` / legacy `rpc.grpc.status_code`; configured request metadata attributes | Stable and legacy RPC semantic conventions are selected by semconv stability configuration; metadata capture requires server request-metadata selector. |
| `message` (event) | — | `message.type` (`SENT`/`RECEIVED`), `message.id` | Controlled by `otel.instrumentation.grpc.emit-message-events` (default true; library builder default true). |
| `{service}/{method}` | SERVER span attributes | `grpc.canceled`, `grpc.received.message_count`, `grpc.sent.message_count` | `grpc.canceled` only when cancelled; experimental attributes require `otel.instrumentation.grpc.experimental-span-attributes`. |
| `{service}/{method}` | CLIENT span attributes | `grpc.received.message_count`, `grpc.sent.message_count` | Experimental attributes require `otel.instrumentation.grpc.experimental-span-attributes`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `rpc.client.call.duration` | Histogram | s | RPC client attributes (`rpc.system.name`, `rpc.method`, `server.address`, `server.port`, and applicable error/status attributes) | Stable RPC metric; legacy dual-emission can also produce `rpc.client.duration` (ms) under semconv stability configuration. |
| `rpc.server.call.duration` | Histogram | s | RPC server attributes (`rpc.system.name`, `rpc.method`, `server.address`, `server.port`, and applicable error/status attributes) | Stable RPC metric; legacy dual-emission can also produce `rpc.server.duration` (ms) under semconv stability configuration. |
| `rpc.client.request.size` | Histogram | By convention | RPC client attributes | Experimental operation size metric; emitted when operation size extraction is enabled by the instrumentation API. |
| `rpc.client.response.size` | Histogram | By convention | RPC client attributes | Experimental operation size metric; emitted when operation size extraction is enabled by the instrumentation API. |
| `rpc.server.request.size` | Histogram | By convention | RPC server attributes | Experimental operation size metric; emitted when operation size extraction is enabled by the instrumentation API. |
| `rpc.server.response.size` | Histogram | By convention | RPC server attributes | Experimental operation size metric; emitted when operation size extraction is enabled by the instrumentation API. |
