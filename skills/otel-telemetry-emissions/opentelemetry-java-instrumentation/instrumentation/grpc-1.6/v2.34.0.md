RPC semconv selection (`SemconvSelectionResolver.rpc()`): declarative `general.rpc.semconv` wins only when `version: 0` (old only) or `version: 1` with `experimental: true` (v1, or old and v1 with `dual_emit: true`); anything else, including `version: 1` without `experimental`, falls back to flags. Flags are the preview list (`java.common.semconv_stability.preview`, else `otel.semconv-stability.preview`) plus, unless v3 preview is on (`java.common.v3_preview`, else `otel.instrumentation.common.v3-preview`), the opt-in list (`general.stability_opt_in_list`, else `general.semconv_stability.opt_in`, else `otel.semconv-stability.opt-in`). `rpc/dup` selects both, `rpc` alone v1 only, neither old only. `SemconvStability` reads the selection once from `GlobalOpenTelemetry` at initialization; a non-global `OpenTelemetry` passed to a library builder does not change it.

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `exception` span event | `exception.type`, `exception.message`, `exception.stacktrace` (when available) | On by default; see the note below the table. |
| `rpc.client.call.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `WARN`; client calls. Off by default; see the note below the table. |
| `rpc.server.call.exception` (log record) | `exception.type`, `exception.message`, `exception.stacktrace` | Severity `ERROR`; server calls. Off by default; see the note below the table. |

`Instrumenter.end` records exception signals only when it receives a throwable. Span status `ERROR` is set independently of these signals, so an `ERROR` status without a throwable records neither the span event nor a log record. `otel.semconv.exception.signal.preview`, or the declarative `general.semconv_exception.signal.preview`, which takes precedence, selects the signals: `logs` records only the log record, `logs/dup` records both, and unset or any other value records only the span event. Log records are emitted even for unsampled spans. The interceptors pass a throwable when `newCall`, the client call's `start` or `sendMessage`, or the server's `startCall`, `close`, or a listener callback other than `onMessage` throws. Otherwise a client call passes the cause of its closing `Status` and a server call the cause of the `Status` given to `close`, if any; a cancelled server call passes none. Exceptions from client listener callbacks and server `onMessage` are not passed.
