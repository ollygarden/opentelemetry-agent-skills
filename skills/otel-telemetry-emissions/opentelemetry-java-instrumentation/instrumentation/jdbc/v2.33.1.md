# JDBC

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| SQL operation name (derived from SQL; stable query summary when available) | CLIENT | Legacy: `db.system`, `db.name`, `db.user`, `db.statement`, `db.operation`, `db.connection_string`, `net.peer.name`, `net.peer.port`. Stable: `db.system.name`, `db.namespace`, `db.query.text`, `db.query.summary`, `db.operation.name`, `db.collection.name`, `db.stored_procedure.name`, `db.operation.batch.size`, `server.address`, `server.port`, `error.type`; opt-in `db.query.parameter.<key>` | `OTEL_SEMCONV_STABILITY_OPT_IN=database` selects stable conventions and `database/dup` emits both; `otel.instrumentation.common.v3-preview=true` forces stable-only conventions; default is legacy. SQL-derived attributes depend on parsed query and available database metadata. Query parameter capture requires `otel.instrumentation.jdbc.experimental.capture-query-parameters` (default false) and disables query sanitization. Java agent also adds `peer.service` when peer service mapping matches. On errors, an `exception` span event is emitted by default; `otel.semconv.exception.signal.preview=logs` switches to logs and `logs/dup` emits both. |
| `COMMIT` or `ROLLBACK` | CLIENT | Legacy: `db.system`, `db.name`, `db.user`, `db.operation`, `db.connection_string`; stable: `db.system.name`, `db.namespace`, `db.operation.name`, `server.address`, `server.port`; `error.type` on error | Transaction instrumentation is disabled by default; enable with `otel.instrumentation.jdbc.experimental.transaction.enabled`. `OTEL_SEMCONV_STABILITY_OPT_IN=database` selects stable conventions and `database/dup` emits both; `otel.instrumentation.common.v3-preview=true` forces stable-only conventions. |
| `{DataSourceClass}.getConnection` | INTERNAL | Legacy: `code.namespace`, `code.function`, `db.system`, `db.name`, `db.user`, `db.connection_string`; stable: `code.function.name`, `db.system.name`, `db.namespace`; available database attributes are added after connection establishment | Java agent `jdbc-datasource` module is default-off; enable with `otel.instrumentation.jdbc-datasource.enabled`. Records only when a valid parent span is current. Stable code/database attributes follow `OTEL_SEMCONV_STABILITY_OPT_IN` (`code`, `database`, or their `/dup` forms) and are forced by `otel.instrumentation.common.v3-preview=true`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | s | Attribute advice: `db.system.name`, `db.namespace`, `db.operation.name`, `db.collection.name`, `db.query.summary`, `server.address`, `server.port`, `network.peer.address`, `network.peer.port`, `error.type` (when available) | Only created and recorded when stable database conventions are selected: `OTEL_SEMCONV_STABILITY_OPT_IN=database` or `database/dup`, or `otel.instrumentation.common.v3-preview=true` (stable-only). Attached to statement operations and enabled transaction operations. SDK attribute advice/views determine which advised attributes are retained. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `db.client.operation.exception` | `exception.type`, `exception.message`, `exception.stacktrace`; severity `WARN` | Emitted on failed statement or transaction operations only when `otel.semconv.exception.signal.preview=logs` or `logs/dup`; default emits the exception as a span event instead. Uses scope `io.opentelemetry.jdbc`. |
| `exception` | `exception.type`, `exception.message`, `exception.stacktrace`; severity `WARN` | Emitted on failed datasource connection spans when the same preview setting is `logs` or `logs/dup`; default emits the exception as a span event instead. Uses scope `io.opentelemetry.jdbc`. |
