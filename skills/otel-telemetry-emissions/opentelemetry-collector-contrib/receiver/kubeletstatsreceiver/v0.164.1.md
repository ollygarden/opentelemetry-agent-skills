### Resource attributes

| Metric group | Resource attributes (enabled by default) | Optional resource attributes | Notes |
|---|---|---|---|
| Node (`k8s.node.*` except `k8s.node.system_container.*`) | `k8s.node.name` | - | - |
| Node system container (`k8s.node.system_container.*`) | `k8s.node.name`, `k8s.node.system_container.name` | - | One resource per kubelet system container. |
| Pod (`k8s.pod.*` except `k8s.pod.volume.usage`) | `k8s.pod.uid`, `k8s.pod.name`, `k8s.namespace.name` | - | - |
| Container (`container.*`, `k8s.container.*`) | `k8s.pod.uid`, `k8s.pod.name`, `k8s.namespace.name`, `k8s.container.name` | `container.id` | `container.id` is added only with `extra_metadata_labels: [container.id]`, which reads the kubelet `/pods` endpoint. |
| Volume (`k8s.volume.*`, `k8s.pod.volume.usage`) | `k8s.pod.uid`, `k8s.pod.name`, `k8s.namespace.name`, `k8s.volume.name` | `k8s.volume.type`, `k8s.persistentvolumeclaim.name` | Optional attributes need `extra_metadata_labels: [k8s.volume.type]`; `k8s.persistentvolumeclaim.name` is set for PVC-backed volumes, whose type is resolved from the bound PersistentVolume when `k8s_api_config` is set. |
