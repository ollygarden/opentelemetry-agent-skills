# File Log Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_fileconsumer_open_files` | UpDownCounter | `1` | - | Development stability; emitted by the fileconsumer meter scope. |
| `otelcol_fileconsumer_reading_files` | UpDownCounter | `1` | - | Development stability; emitted by the fileconsumer meter scope. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| File log record | `log.file.name`; `log.file.path`; `log.file.name_resolved`; `log.file.path_resolved`; `log.file.owner.name`; `log.file.owner.group.name`; `log.file.permissions`; `log.file.record_number`; `log.file.record_offset`; user-configured attributes | Only `log.file.name` is added by default (`include_file_name: true`); the others need `include_file_path`, `include_file_name_resolved`, `include_file_path_resolved`, `include_file_owner_name`, `include_file_owner_group_name`, `include_file_permissions`, `include_file_record_number`, or `include_file_record_offset`. Operators may add or change attributes. The record body contains the read file entry. |
