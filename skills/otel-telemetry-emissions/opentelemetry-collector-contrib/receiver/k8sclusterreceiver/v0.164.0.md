### Resource attributes

Each Kubernetes object's metrics are emitted on that object's entity resource. Attributes are enabled by default unless listed as optional; optional ones need `resource_attributes.<name>.enabled: true`.

| Metric group | Resource attributes (enabled by default) | Optional resource attributes | Notes |
|---|---|---|---|
| `k8s.container.*` | `container.id`, `k8s.container.name`, `container.image.name`, `container.image.tag`, `k8s.pod.uid`, `k8s.pod.name`, `k8s.namespace.name`, `k8s.node.name` | `k8s.container.status.last_terminated_reason` | `k8s.container.status.last_terminated_reason` is empty unless the last state is terminated. |
| `k8s.pod.*` | `k8s.pod.uid`, `k8s.pod.name`, `k8s.namespace.name`, `k8s.node.name` | `k8s.pod.qos_class` | - |
| `k8s.node.condition` | `k8s.node.uid`, `k8s.node.name` | `k8s.kubelet.version` | - |
| `k8s.node.condition_<condition>`, `k8s.node.allocatable_<resource>` | `k8s.node.uid`, `k8s.node.name` | `k8s.kubelet.version`, `os.type`, `os.description`, `container.runtime`, `container.runtime.version` | `container.runtime` and `container.runtime.version` are set only when the kubelet reports `<runtime>://<version>`. |
| `k8s.namespace.phase` | `k8s.namespace.uid`, `k8s.namespace.name` | - | - |
| `k8s.deployment.*` | `k8s.deployment.uid`, `k8s.deployment.name`, `k8s.namespace.name` | - | - |
| `k8s.replicaset.*` | `k8s.replicaset.uid`, `k8s.replicaset.name`, `k8s.namespace.name` | - | - |
| `k8s.statefulset.*` | `k8s.statefulset.uid`, `k8s.statefulset.name`, `k8s.namespace.name` | - | - |
| `k8s.daemonset.*` | `k8s.daemonset.uid`, `k8s.daemonset.name`, `k8s.namespace.name` | - | - |
| `k8s.cronjob.*` | `k8s.cronjob.uid`, `k8s.cronjob.name`, `k8s.namespace.name` | - | - |
| `k8s.job.*` | `k8s.job.uid`, `k8s.job.name`, `k8s.namespace.name` | - | - |
| `k8s.replication_controller.*` | `k8s.replicationcontroller.uid`, `k8s.replicationcontroller.name`, `k8s.namespace.name` | - | - |
| `k8s.resource_quota.*` | `k8s.resourcequota.uid`, `k8s.resourcequota.name`, `k8s.namespace.name` | - | - |
| `k8s.hpa.*` | `k8s.hpa.uid`, `k8s.hpa.name`, `k8s.namespace.name` | `k8s.hpa.scaletargetref.apiversion`, `k8s.hpa.scaletargetref.kind`, `k8s.hpa.scaletargetref.name` | - |
| `k8s.persistentvolume.*` | `k8s.persistentvolume.uid`, `k8s.persistentvolume.name`, `k8s.storageclass.name` | `k8s.persistentvolume.reclaim_policy` | `k8s.storageclass.name` is empty when the object has no storage class. |
| `k8s.persistentvolumeclaim.*` | `k8s.persistentvolumeclaim.uid`, `k8s.persistentvolumeclaim.name`, `k8s.namespace.name`, `k8s.storageclass.name` | - | `k8s.storageclass.name` is empty when the object has no storage class. |
| `k8s.service.*` | `k8s.service.uid`, `k8s.service.name`, `k8s.namespace.name`, `k8s.service.type` | `k8s.service.publish_not_ready_addresses`, `k8s.service.traffic_distribution` | `k8s.service.traffic_distribution` is added only when set on the Service. |
| `openshift.*` | `openshift.clusterquota.uid`, `openshift.clusterquota.name` | - | - |

`container.id` comes from the container status and is empty before the runtime creates the container. `container.image.name` and `container.image.tag` are parsed from the container status image; all three are empty when the container has no status yet. Entity attributes that are enabled but unknown are written as empty strings. When an entity's identifying attribute is enabled, the resource also carries an entity reference for that object, except for `k8s.node.condition_<condition>`, `k8s.node.allocatable_<resource>`, and `k8s.service.*` metrics, whose resources carry plain resource attributes only.
