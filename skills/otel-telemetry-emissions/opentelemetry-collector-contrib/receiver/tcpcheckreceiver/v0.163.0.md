# TCP Check Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| tcpcheck.duration | Gauge | ms | `tcpcheck.endpoint` | Emitted on successful TCP checks. |
| tcpcheck.error | Monotonic cumulative sum | {error} | `tcpcheck.endpoint`, `error.code` | Emitted on failed checks. `tcpcheck.endpoint` is a required attribute; `error.code` is always emitted because the receiver ignores the configured attribute list (see below). |
| tcpcheck.status | Gauge | 1 | `tcpcheck.endpoint` | 1 for successful connection, 0 for failure. |

The scraper builds its metrics builder from `metadata.NewDefaultMetricsBuilderConfig()` instead of the receiver config, so all three metrics are always enabled with their default attributes, and each is emitted only on the outcomes in its row; per-metric `enabled` and `attributes` settings have no effect.
