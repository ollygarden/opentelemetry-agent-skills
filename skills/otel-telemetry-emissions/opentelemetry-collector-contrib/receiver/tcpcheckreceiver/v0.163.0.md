# TCP Check Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| tcpcheck.duration | Gauge | ms | `tcpcheck.endpoint` | Emitted on successful TCP checks. |
| tcpcheck.error | Monotonic cumulative sum | {error} | `tcpcheck.endpoint`, `error.code` | Emitted on failed checks; attributes are individually enabled through the metric's `enabled` attributes config. |
| tcpcheck.status | Gauge | 1 | `tcpcheck.endpoint` | 1 for successful connection, 0 for failure. |
