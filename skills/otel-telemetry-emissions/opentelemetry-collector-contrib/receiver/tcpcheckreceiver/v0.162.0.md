# TCP Check Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `tcpcheck.duration` | Gauge (int) | `ms` | `tcpcheck.endpoint` | Enabled by default; stability `alpha`. Recorded only when the TCP dial succeeds. |
| `tcpcheck.error` | Sum (cumulative, monotonic, int) | `{error}` | `tcpcheck.endpoint`, `error.code` | Enabled by default; stability `alpha`. Recorded only when the TCP dial fails; `error.code` is one of `connection_refused`, `connection_timeout`, `invalid_endpoint`, `network_unreachable`, `unknown_error`, classified from the dial error string. |
| `tcpcheck.status` | Gauge (int) | `1` | `tcpcheck.endpoint` | Enabled by default; stability `alpha`. `1` on successful connect, `0` on failure. |

Each metric is emitted once per configured target per collection interval, and can be disabled via `metrics::<name>::enabled: false`.
