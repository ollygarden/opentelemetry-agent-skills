# TCP Check Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `tcpcheck.duration` | Gauge (int) | `ms` | `tcpcheck.endpoint` | Enabled by default; stability `development`. Recorded only when the TCP dial succeeds. |
| `tcpcheck.error` | Sum (cumulative, monotonic, int) | `{errors}` | `tcpcheck.endpoint`, `error.code` | Enabled by default; stability `development`. Recorded only when the TCP dial fails; `error.code` is one of `connection_refused`, `connection_timeout`, `invalid_endpoint`, `network_unreachable`, `unknown_error`, classified from the dial error string. |
| `tcpcheck.status` | Gauge (int) | `1` | `tcpcheck.endpoint` | Enabled by default; stability `development`. `1` on successful connect, `0` on failure. |

The scraper builds its metrics builder from `metadata.NewDefaultMetricsBuilderConfig()` instead of the receiver config, so all three metrics are always enabled with their default attributes, and each is emitted only on the outcomes in its row; per-metric `enabled` and `attributes` settings have no effect.
