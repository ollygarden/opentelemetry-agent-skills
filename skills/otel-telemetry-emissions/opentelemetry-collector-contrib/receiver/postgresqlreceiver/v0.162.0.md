## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `db.server.query_plan` | db.system.name, postgresql.queryid, db.namespace, postgresql.rolname, postgresql.query_plan | Disabled by default; enable the event in receiver.logs. Requires `db.server.top_query` to be enabled; emitted during top query collection only for queries with a non-empty plan. When enabled, `postgresql.query_plan` is removed from `db.server.top_query` records. |
| `db.server.query_sample` | db.system.name, db.namespace, db.query.text, user.name, postgresql.state, postgresql.pid, postgresql.backend.connection.start, postgresql.application_name, network.peer.address, network.peer.port, postgresql.client_hostname, postgresql.query_start, postgresql.wait_event, postgresql.wait_event_type, postgresql.query_id, postgresql.total_exec_time, postgresql.blocking.pids, postgresql.blocking.start_time, postgresql.blocking.wait_duration, postgresql.blocking.lock.mode, postgresql.blocking.lock.type, postgresql.blocking.lock.relation, postgresql.blocking.transaction.start_time | Disabled by default; enable the event in receiver.logs. `postgresql.total_exec_time` is expressed in seconds. `postgresql.backend.connection.start` is an RFC3339 UTC timestamp. Query samples may carry trace/span IDs when application_name contains a valid W3C traceparent. |
| `db.server.top_query` | db.system.name, db.namespace, db.query.text, postgresql.calls, postgresql.rows, postgresql.shared_blks_dirtied, postgresql.shared_blks_hit, postgresql.shared_blks_read, postgresql.shared_blks_written, postgresql.temp_blks_read, postgresql.temp_blks_written, postgresql.queryid, postgresql.rolname, postgresql.total_exec_time, postgresql.total_plan_time, postgresql.query_plan | Disabled by default; enable the event in receiver.logs. `postgresql.total_exec_time` and `postgresql.total_plan_time` are expressed in seconds. Statements whose database no longer exists are skipped. `postgresql.query_plan` is omitted when `db.server.query_plan` is enabled. |
