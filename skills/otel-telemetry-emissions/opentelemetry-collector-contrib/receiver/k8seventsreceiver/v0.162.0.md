# Kubernetes Events Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_k8s_events_modified_filtered` | Counter | `{event}` | - | Counts MODIFIED watch events filtered by `dedup_interval`; always 0 when `dedup_interval` is not set. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `k8s.event` | `k8s.event.reason`, `k8s.event.action`, `k8s.event.start_time`, `k8s.event.name`, `k8s.event.uid`, `k8s.namespace.name`, `k8s.event.reporting_controller`, `k8s.event.reporting_instance`, `k8s.event.count` (when nonzero); resource attributes `k8s.node.name`, `k8s.object.kind`, `k8s.object.name`, `k8s.object.uid`, `k8s.object.fieldpath`, `k8s.object.api_version`, `k8s.object.resource_version` | Emits accepted ADDED events and MODIFIED events allowed by `dedup_interval`; DELETED events and events older than receiver startup are excluded. `k8s.event.count` is omitted when zero. Severity is mapped from event type `Normal`, `Warning`, `Error`, or `Critical`. |
