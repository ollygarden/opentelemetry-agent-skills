# icmpcheckreceiver

## Metrics

All metrics are emitted once per configured `targets[]` entry per scrape interval, on a separate resource carrying the target's resource attributes. All are `enabled: true` by default and can be disabled via `metrics::<name>::enabled: false`. Component metrics stability is `development`.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `ping.loss.ratio` | Gauge (Double) | `%` | Resource: `net.peer.ip`, `net.peer.name` | The percentage of lost packets. Taken from pro-bing `Statistics.PacketLoss`. |
| `ping.rtt.avg` | Gauge (Double) | `ms` | Resource: `net.peer.ip`, `net.peer.name` | Average round-trip time. Recorded as `stats.avgRtt.Seconds()*1000` (sub-millisecond precision). |
| `ping.rtt.max` | Gauge (Double) | `ms` | Resource: `net.peer.ip`, `net.peer.name` | Maximum round-trip time. Recorded as `stats.maxRtt.Seconds()*1000` (sub-millisecond precision). |
| `ping.rtt.min` | Gauge (Double) | `ms` | Resource: `net.peer.ip`, `net.peer.name` | Minimum round-trip time. Recorded as `stats.minRtt.Seconds()*1000` (sub-millisecond precision). |
| `ping.rtt.stddev` | Gauge (Double) | `ms` | Resource: `net.peer.ip`, `net.peer.name` | Standard deviation of round-trip time. Recorded as `stats.stdDevRtt.Seconds()*1000` (sub-millisecond precision). |

### Resource attributes

| Attribute | Type | Enabled by default | Notes |
|---|---|---|---|
| `net.peer.ip` | string | yes | IP address of the pinged host, from `pinger.IPString()`. Empty when the ping failed. |
| `net.peer.name` | string | yes | Hostname of the pinged host, the configured `targets[].host`. |

No metrics are emitted for a target whose ping returned an error; the scrape logs the failure instead.

## Logs

The receiver emits no OTLP log records into its pipeline. It writes the following to the Collector's internal (zap) logger.

| Log/event name | Attributes | Notes |
|---|---|---|
| `failed to ping host` (ERROR) | `host` (target hostname), `error` | Emitted per target when `pinger.Run()` or pinger construction fails; that target contributes no metrics for the scrape. |
