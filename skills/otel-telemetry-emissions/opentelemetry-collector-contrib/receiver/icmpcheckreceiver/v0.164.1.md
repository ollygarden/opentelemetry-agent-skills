# ICMP Check Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| ping.loss.ratio | Gauge | % | Resource: net.peer.ip, net.peer.name | - |
| ping.rtt.avg | Gauge | ms | Resource: net.peer.ip, net.peer.name | - |
| ping.rtt.max | Gauge | ms | Resource: net.peer.ip, net.peer.name | - |
| ping.rtt.min | Gauge | ms | Resource: net.peer.ip, net.peer.name | - |
| ping.rtt.stddev | Gauge | ms | Resource: net.peer.ip, net.peer.name | - |

### Resource attributes

| Attribute | Type | Enabled by default | Notes |
|---|---|---|---|
| net.peer.ip | string | yes | - |
| net.peer.name | string | yes | - |

One resource per target whose ping run completes without error, even if no replies arrive (`ping.loss.ratio` is then 100). A target whose pinger setup or run returns an error emits no metrics.
