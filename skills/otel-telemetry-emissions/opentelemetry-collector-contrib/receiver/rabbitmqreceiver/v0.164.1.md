Enable a disabled-by-default metric with `metrics.<name>.enabled: true` in the receiver config.

Resource attributes: queue metrics (`rabbitmq.consumer.count`, `rabbitmq.message.*`) are emitted on a per-queue resource with `rabbitmq.queue.name`, `rabbitmq.node.name`, and `rabbitmq.vhost.name`; node metrics (`rabbitmq.node.*`) on a per-node resource with `rabbitmq.node.name`; exchange metrics (`rabbitmq.exchange.messages.*`) on a per-exchange resource with `rabbitmq.exchange.name`, `rabbitmq.exchange.type`, and `rabbitmq.vhost.name`. `rabbitmq.cluster.name` is disabled by default; when enabled, it is added to every resource if the cluster-name request succeeds. The Attributes column lists datapoint attributes only.
