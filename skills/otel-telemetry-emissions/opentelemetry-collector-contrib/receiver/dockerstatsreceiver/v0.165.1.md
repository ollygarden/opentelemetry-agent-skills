Enable a disabled-by-default metric with `metrics.<name>.enabled: true` in the receiver config.

### Resource attributes

Every metric except `container.state.status` is emitted on a per-container resource.

| Attribute | Type | Enabled by default | Notes |
|---|---|---|---|
| `container.runtime` | string | yes | Always `docker`. |
| `container.hostname` | string | yes | - |
| `container.id` | string | yes | - |
| `container.image.name` | string | yes | Image reference from the container config. |
| `container.name` | string | yes | Leading `/` removed. |
| `container.image.id` | string | no | Enable with `resource_attributes.container.image.id.enabled`. |
| `container.command_line` | string | no | Enable with `resource_attributes.container.command_line.enabled`. |
| configured label names | string | - | Added from `env_vars_to_metric_labels` and `container_labels_to_metric_labels` when the mapped environment variable or container label is non-empty. |
