Enable a disabled-by-default metric with `metrics.<name>.enabled: true` under the scraper's config (`scrapers.<scraper>`).

Boot-time handling for every `process` scraper metric follows `hostmetrics.process.bootTimeCache`.

### Instrumentation scopes

Each scraper emits its metrics under its own scope, not the receiver scope in `scope_name`. The host entity state log uses an unnamed scope marked with `otel.entity.event_as_log=true`.

| `cpu` | `github.com/open-telemetry/opentelemetry-collector-contrib/receiver/hostmetricsreceiver/internal/scraper/cpuscraper` |

### Resource attributes

Only the `process` scraper sets resource attributes: one resource per scraped process.

| Attribute | Type | Enabled by default | Notes |
|---|---|---|---|
| `process.pid` | int | yes | - |
| `process.parent_pid` | int | yes | - |
| `process.executable.name` | string | yes | - |
| `process.executable.path` | string | yes | - |
| `process.command` | string | yes | Set when the process command can be read. |
| `process.command_line` | string | yes | Full command line joined with spaces; set when the process command can be read. |
| `process.owner` | string | yes | Set when the owner username is non-empty. |
| `process.cgroup` | string | no | Linux only; enable with `resource_attributes.process.cgroup.enabled`. |
