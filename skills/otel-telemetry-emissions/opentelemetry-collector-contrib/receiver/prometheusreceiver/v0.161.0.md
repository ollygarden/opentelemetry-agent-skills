# Prometheus Receiver

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `<Prometheus gauge family>` | Gauge | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Any scraped gauge or unknown-typed family; metric name, description, and unit come from the scrape payload metadata. |
| `<Prometheus counter family>` | Sum (cumulative, monotonic) | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Scraped counter families. Created timestamps are used when present; zero-valued created samples are injected when feature gate `receiver.prometheusreceiver.EnableCreatedTimestampZeroIngestion` is enabled. |
| `<Prometheus info or stateset family>` | Sum (cumulative, non-monotonic) | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Prometheus info and stateset types are represented as non-monotonic sums. |
| `<Prometheus classic histogram family>` | Histogram (cumulative) | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, `le`, and `otel_scope_*` | Classic Prometheus histogram bucket, sum, and count series are combined into one OTLP histogram. |
| `<Prometheus native histogram family>` | Exponential Histogram (cumulative) | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Prometheus native histograms are converted to OTLP exponential histograms. |
| `<Prometheus native histogram custom-bucket family>` | Histogram (cumulative) | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Native histogram custom-bucket schema (`-53`) is converted to an OTLP histogram. |
| `<Prometheus summary family>` | Summary | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, `quantile`, and `otel_scope_*` | Prometheus summary quantile, sum, and count series are combined into one OTLP summary. |
| `up` | Gauge | `1` | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Built-in Prometheus scrape health metric. |
| `scrape_duration_seconds` | Gauge | `s` | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Built-in Prometheus scrape metric. |
| `scrape_samples_scraped` | Gauge | `1` | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Built-in Prometheus scrape metric. |
| `scrape_series_added` | Gauge | `1` | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Built-in Prometheus scrape metric. |
| `scrape_samples_post_metric_relabeling` | Gauge | `1` | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Built-in Prometheus scrape metric. |
| `otel_scope_info` | Gauge | Prometheus metadata unit, converted to UCUM | Prometheus labels except `__name__`, `job`, `instance`, `scheme`, `metrics_path`, and `otel_scope_*` | Only emitted as a metric when feature gate `receiver.prometheusreceiver.IgnoreScopeInfoMetric` is enabled (beta, enabled by default); when the gate is disabled, converted into scope name, version, schema URL, and attributes. |
