# HTTP Check Receiver

Component type `http_check` (deprecated alias `httpcheck`). Metrics stability: alpha. Metrics are scraped per configured target endpoint per collection interval, subject to the per-metric conditions in Notes; each can be toggled with `metrics::<name>::enabled`.

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `httpcheck.duration` | Gauge (int) | `ms` | `http.url` | Enabled by default; stability `development`. Wall-clock time of `client.Do`, recorded on every scrape including failures. |
| `httpcheck.error` | Sum (cumulative, non-monotonic, int) | `{error}` | `http.url`, `error.message` | Enabled by default; stability `development`. Recorded with value `1` only when the request returns an error; `error.message` is the Go error string. |
| `httpcheck.status` | Sum (cumulative, non-monotonic, int) | `1` | `http.url`, `http.status_code`, `http.method`, `http.status_class` | Enabled by default; stability `development`. One data point per status class (`1xx`–`5xx`) per scrape: `1` for the matching class, `0` for the others. For the `0`-valued points the `http.status_code` attribute is stripped by `removeStatusCodeForZeroValues` after `Emit`. |
| `httpcheck.response.size` | Gauge (int) | `By` | `http.url` | Disabled by default (`metrics::httpcheck.response.size::enabled: true`); stability `development`. Recorded only when the response body is non-empty. |
| `httpcheck.dns.lookup.duration` | Gauge (int) | `ns` | `http.url` | Disabled by default; stability `development`. From `httptrace` `DNSStart`/`DNSDone`; recorded every scrape, `0` when the phase did not occur (e.g. connection reuse or cached DNS). |
| `httpcheck.client.connection.duration` | Gauge (int) | `ns` | `http.url`, `network.transport` | Disabled by default; stability `development`. From `httptrace` `ConnectStart`/`ConnectDone`; `network.transport` is always the literal `tcp`. `0` when no new connection was established. |
| `httpcheck.tls.handshake.duration` | Gauge (int) | `ns` | `http.url` | Disabled by default; stability `development`. From `httptrace` `TLSHandshakeStart`/`TLSHandshakeDone`; `0` for plaintext HTTP or reused connections. |
| `httpcheck.client.request.duration` | Gauge (int) | `ns` | `http.url` | Disabled by default; stability `development`. Request-write phase (request start to `WroteRequest`). |
| `httpcheck.response.duration` | Gauge (int) | `ns` | `http.url` | Disabled by default; stability `development`. Response-read phase (`GotFirstResponseByte` to end of `client.Do`). |
| `httpcheck.tls.cert_remaining` | Gauge (int) | `s` | `http.url`, `http.tls.issuer`, `http.tls.cn`, `http.tls.san` | Disabled by default; stability `development`. Recorded only when the metric is enabled, the response carries TLS state with at least one peer certificate, and at least one of issuer, CN, or SANs is non-empty. Seconds until `NotAfter`; negative after expiry. `http.tls.san` is a slice of IPs, URIs, DNS names and email addresses. |
| `httpcheck.validation.passed` | Sum (cumulative, non-monotonic, int) | `{validation}` | `http.url`, `validation.type` | Disabled by default; stability `development`. Requires `targets::validations` to be configured and a non-empty response body. `validation.type` is one of `contains`, `not_contains`, `json_path`, `size`, `regex`. |
| `httpcheck.validation.failed` | Sum (cumulative, non-monotonic, int) | `{validation}` | `http.url`, `validation.type` | Disabled by default; stability `development`. Same gating and `validation.type` values as `httpcheck.validation.passed`. |

No resource attributes are defined by this component.
