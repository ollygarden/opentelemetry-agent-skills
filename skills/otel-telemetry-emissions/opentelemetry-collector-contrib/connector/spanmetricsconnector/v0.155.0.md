# Span Metrics Connector

## Metrics

Metric names use `<namespace>.<metric>` with default namespace `traces.span.metrics`. An empty namespace emits `calls`, `duration`, and `events`; gate `connector.spanmetrics.legacyMetricNames` also removes the default namespace for all three metrics.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `traces.span.metrics.calls` | Sum (monotonic) | 1 | `service.name`, `span.name`, `span.kind`, `status.code`; configured `dimensions` and `calls_dimensions` (including matching `glob` dimensions); optional `span.instrumentation.scope.name`, `span.instrumentation.scope.version`, `sampling.method` | Always emitted for spans with `service.name`; `status.code` is replaced by `otel.status_code` when gate `spanmetrics.statusCodeConvention.useOtelPrefix` is enabled. `collector.instance.id` is added when gate `connector.spanmetrics.includeCollectorInstanceID` is enabled. Legacy gate `connector.spanmetrics.legacyMetricNames` changes the default name to `calls`. |
| `traces.span.metrics.duration` | Histogram (explicit or exponential) | `ms` by default; `s` when gate `connector.spanmetrics.useSecondAsDefaultMetricsUnit` is enabled (or as configured) | `service.name`, `span.name`, `span.kind`, `status.code`; configured `dimensions` and histogram `dimensions`; optional scope, sampling, and collector-instance attributes as above | Omitted when `histogram.disable` is true. Same status/name/collector gates as `calls`. |
| `traces.span.metrics.events` | Sum (monotonic) | 1 | `service.name`, `span.name`, `span.kind`, `status.code`; configured `dimensions` and event `dimensions`; optional scope, sampling, and collector-instance attributes as above | Emitted only when `events.enabled` is true, one data point per span event. Same status/name/collector gates as `calls`. |

Resource attributes are attached to output ResourceMetrics unless gate `connector.spanmetrics.excludeResourceMetrics` is enabled (the `add_resource_attributes` setting restores them). `exclude_dimensions` removes default dimensions; configured named/glob dimensions are conditional on matching attributes. Event dimensions also use event attributes. When `aggregation_cardinality_limit` is reached, the overflow data point has only `otel.metric.overflow=true`. Exemplars are optional and carry trace/span IDs.
