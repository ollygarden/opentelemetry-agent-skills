# spanmetricsconnector

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `traces.span.metrics.calls` | monotonic sum (counter) | `""` | `service.name`, `span.name`, `span.kind`, `status.code`; additional configured `dimensions` and `calls_dimensions`; optionally `otel.status_code` instead of `status.code`; `collector.instance.id` unless `connector.spanmetrics.includeCollectorInstanceID` (beta, enabled by default) is disabled; optionally `span.instrumentation.scope.name` and `span.instrumentation.scope.version`; optionally `sampling.method`; `otel.metric.overflow` on cardinality overflow | Spans whose resource lacks `service.name` are skipped and produce no data points. Namespace configurable; `connector.spanmetrics.legacyMetricNames` alpha gate (default disabled) removes the default `traces.span.metrics` namespace. `spanmetrics.statusCodeConvention.useOtelPrefix` alpha gate (default disabled) switches status attribute to `otel.status_code`. `collector.instance.id` is added by the `connector.spanmetrics.includeCollectorInstanceID` gate (beta, enabled by default) and omitted when the gate is disabled or the dimension is listed in `exclude_dimensions`. |
| `traces.span.metrics.duration` | explicit or exponential histogram | `ms` by default | `service.name`, `span.name`, `span.kind`, `status.code`; additional configured `dimensions` and `histogram.dimensions`; optionally `otel.status_code` instead of `status.code`; `collector.instance.id` unless `connector.spanmetrics.includeCollectorInstanceID` (beta, enabled by default) is disabled; optionally `span.instrumentation.scope.name` and `span.instrumentation.scope.version`; optionally `sampling.method`; `otel.metric.overflow` on cardinality overflow | Spans whose resource lacks `service.name` are skipped and produce no data points. Disabled by `histogram.disable`; unit is `histogram.unit` (`ms` or `s`), which defaults to `ms`, or `s` when the `connector.spanmetrics.useSecondAsDefaultMetricsUnit` alpha gate is enabled (default disabled); namespace configurable and subject to `connector.spanmetrics.legacyMetricNames` as above. |
| `traces.span.metrics.events` | monotonic sum (counter) | `""` | `service.name`, `span.name`, `span.kind`, `status.code`; additional configured `dimensions` and `events.dimensions`; optionally `otel.status_code` instead of `status.code`; `collector.instance.id` unless `connector.spanmetrics.includeCollectorInstanceID` (beta, enabled by default) is disabled; optionally `span.instrumentation.scope.name` and `span.instrumentation.scope.version`; optionally `sampling.method`; `otel.metric.overflow` on cardinality overflow | Spans whose resource lacks `service.name` are skipped and produce no data points. Emitted only when `events.enabled`; namespace configurable and subject to `connector.spanmetrics.legacyMetricNames` as above. |

`exclude_dimensions` removes any listed dimension, including `service.name`, `span.name`, `span.kind`, and the status attribute, from all three metrics. With `spanmetrics.statusCodeConvention.useOtelPrefix` enabled, `otel.status_code` is set only for `ERROR` and `OK` spans; spans with unset status carry no status attribute.
