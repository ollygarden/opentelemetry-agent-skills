# spanmetricsconnector

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| calls (or configured namespace_calls) | Sum (monotonic) | 1 | service.name, span.name, span.kind, status.code (or otel.status_code), configured dimensions; otel.metric.overflow on cardinality overflow; sampling.method when adjusted | - |
| duration (or configured namespace_duration) | Histogram (explicit or exponential) | Configured histogram unit (default ms; s with feature gate connector.spanmetrics.useSecondAsDefaultMetricsUnit) | service.name, span.name, span.kind, status.code (or otel.status_code), configured histogram dimensions; otel.metric.overflow on cardinality overflow; sampling.method when adjusted | - |
| events (or configured namespace_events) | Sum (monotonic) | 1 | service.name, span.name, span.kind, status.code (or otel.status_code), configured dimensions; event.name and configured event dimensions; otel.metric.overflow on cardinality overflow | Emitted only when events are enabled/configured |
