# Span Metrics Connector

## Metrics

Metric names use `<namespace>.<metric>` with default namespace `traces.span.metrics`. An empty namespace emits `calls`, `duration`, and `events`; gate `connector.spanmetrics.legacyMetricNames` also removes the default namespace for all three metrics.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `traces.span.metrics.calls` | Sum (monotonic) | 1 | `service.name`, `span.name`, `span.kind`, `status.code`; configured `dimensions` and `calls_dimensions`; optional `span.instrumentation.scope.name`, `span.instrumentation.scope.version`, `sampling.method` | Always emitted for spans with `service.name`; status attribute uses `otel.status_code` under gate `spanmetrics.statusCodeConvention.useOtelPrefix`. `collector.instance.id` is gated by `connector.spanmetrics.includeCollectorInstanceID`. Legacy gate `connector.spanmetrics.legacyMetricNames` changes the default name to `calls`. |
| `traces.span.metrics.duration` | Histogram (explicit or exponential) | `ms` by default; `s` under gate `connector.spanmetrics.useSecondAsDefaultMetricsUnit` (or as configured) | `service.name`, `span.name`, `span.kind`, `status.code`; configured `dimensions` and histogram `dimensions`; optional scope, sampling, and collector-instance attributes as above | Omitted when `histogram.disable` is true. |
| `traces.span.metrics.events` | Sum (monotonic) | 1 | `service.name`, `span.name`, `span.kind`, `status.code`; configured `dimensions` and event `dimensions`; optional scope, sampling, and collector-instance attributes as above | Emitted only when `events.enabled` is true, one data point per span event. |

Resource attributes are attached to output ResourceMetrics unless gate `connector.spanmetrics.excludeResourceMetrics` is enabled (the `add_resource_attributes` setting restores them). `exclude_dimensions` removes default dimensions; configured dimensions are conditional on matching attributes. When `aggregation_cardinality_limit` is reached, the overflow data point has only `otel.metric.overflow=true`. Exemplars are optional and carry trace/span IDs.
