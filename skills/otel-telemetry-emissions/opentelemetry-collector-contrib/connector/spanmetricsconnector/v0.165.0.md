# spanmetricsconnector

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `traces.span.metrics.calls` | monotonic sum (counter) | `1` | `service.name`, `span.name`, `span.kind`, `status.code`; additional configured `dimensions` and `calls_dimensions`; optionally `otel.status_code` instead of `status.code`; optionally `collector.instance.id`; optionally `span.instrumentation.scope.name` and `span.instrumentation.scope.version`; optionally `sampling.method`; `otel.metric.overflow` on cardinality overflow | Namespace configurable; `connector.spanmetrics.legacyMetricNames` alpha gate (default disabled) removes the default `traces.span.metrics` namespace. `spanmetrics.statusCodeConvention.useOtelPrefix` alpha gate (default disabled) switches status attribute to `otel.status_code`. Collector instance ID is gated by `connector.spanmetrics.includeCollectorInstanceID` (beta, default disabled). |
| `traces.span.metrics.duration` | explicit or exponential histogram | `ms` by default | `service.name`, `span.name`, `span.kind`, `status.code`; additional configured `dimensions` and `histogram.dimensions`; optionally `otel.status_code` instead of `status.code`; optionally `collector.instance.id`; optionally `span.instrumentation.scope.name` and `span.instrumentation.scope.version`; optionally `sampling.method`; `otel.metric.overflow` on cardinality overflow | Disabled by `histogram.disable`; unit defaults to `ms`, or `s` when `connector.spanmetrics.useSecondAsDefaultMetricsUnit` alpha gate is enabled (default disabled); namespace configurable and subject to `connector.spanmetrics.legacyMetricNames` as above. |
| `traces.span.metrics.events` | monotonic sum (counter) | `1` | `service.name`, `span.name`, `span.kind`, `status.code`; additional configured `dimensions` and `events.dimensions`; optionally `otel.status_code` instead of `status.code`; optionally `collector.instance.id`; optionally `span.instrumentation.scope.name` and `span.instrumentation.scope.version`; optionally `sampling.method`; `otel.metric.overflow` on cardinality overflow | Emitted only when `events.enabled`; namespace configurable and subject to `connector.spanmetrics.legacyMetricNames` as above. |
