# Tail Sampling Processor

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `tailsampling.ConsumeTraces` | Internal | `traces.count`, `spans.count`, `resource_spans.count` | Attributes are set when the span is recording. |
| `tailsampling.samplingPolicyOnTick` | Internal | `batch.size`, `policy.count`, `policy.errors`, `decisions.sampled`, `decisions.not_sampled`, `decisions.dropped` | Emitted for non-empty decision batches; status is Error when policy evaluation errors occur. With feature gate `processor.tailsamplingprocessor.recordpolicy`, processed output ScopeSpans may also receive `tailsampling.policy`, `tailsampling.composite_policy`, and `tailsampling.cached_decision`. |
