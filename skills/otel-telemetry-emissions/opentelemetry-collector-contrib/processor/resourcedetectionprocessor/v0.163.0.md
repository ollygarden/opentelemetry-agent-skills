# Resource Detection Processor

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol.resourcedetection.attributes.detected` | Observable UpDownCounter (int) | `{attribute}` | - | Asynchronously observes the number of attributes in the currently detected resource. |
| `otelcol.resourcedetection.detector.duration` | Histogram (double) | `s` | `detector`, `outcome` | Records the time taken by each detector, including retry backoff. |
| `otelcol.resourcedetection.detector.results` | Counter (int) | `{detection}` | `detector`, `outcome`, `error.type` | Records one result per detector; `error.type` is present on failure. |
