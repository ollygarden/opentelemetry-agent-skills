# Resource Detection Processor

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol.resourcedetection.attributes.detected` | Observable UpDownCounter (int) | `{attribute}` | - | Callback observes the number of attributes in the detected resource when one is available. |
| `otelcol.resourcedetection.detector.duration` | Histogram (double) | `s` | `detector`, `outcome` | Records per-detector elapsed time, including retry backoff. |
| `otelcol.resourcedetection.detector.results` | Counter (int) | `{detection}` | `detector`, `outcome`, `error.type` | `error.type` is added only for failures. |
