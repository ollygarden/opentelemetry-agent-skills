# Prometheus Remote Write Exporter

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_exporter_prometheusremotewrite_consumers` | Sum (int, non-monotonic) | `{consumer}` | `exporter`; `endpoint` | Development stability. Set once at exporter startup to the configured ceiling on parallel export requests, not a live worker count. The ceiling is `remote_write_queue.num_consumers`, or the literal 5 if the `exporter.prometheusremotewritexporter.EnableMultipleWorkers` feature gate (alpha, disabled by default) is enabled. `max_batch_request_parallelism` overrides both, and a floor of 1 applies last. Both paths report 5 by default. |
| `otelcol_exporter_prometheusremotewrite_failed_translations` | Sum (int, monotonic) | `1` | `exporter`; `endpoint` | Development stability. Incremented each time the pmetric-to-Prometheus translation returns an error. |
| `otelcol_exporter_prometheusremotewrite_sent_batches` | Sum (int, monotonic) | `{batch}` | `exporter`; `endpoint` | Development stability. Incremented once per remote-write request attempt sent, regardless of the outcome. |
| `otelcol_exporter_prometheusremotewrite_translated_time_series` | Sum (int, monotonic) | `1` | `exporter`; `endpoint` | Development stability. Incremented by the number of Prometheus time series produced by the translation. |
| `otelcol_exporter_prometheusremotewrite_wal_bytes_read` | Sum (int, monotonic) | `By` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). |

| `otelcol_exporter_prometheusremotewrite_wal_send_failed_batches` | Sum (int, monotonic) | `{batch}` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). Incremented by the number of write requests the endpoint rejected (HTTP 400, 409, 413 or 422) when every failure in a WAL batch is such a rejection; the batch is then dropped from the WAL. Other failures keep the batch and are not counted. |
| `otelcol_exporter_prometheusremotewrite_wal_send_failed_samples` | Sum (int, monotonic) | `{sample}` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). Incremented by the samples and native histograms carried by the requests counted in `otelcol_exporter_prometheusremotewrite_wal_send_failed_batches`; an upper bound on the samples lost. |
| `otelcol_exporter_prometheusremotewrite_wal_write_latency` | Histogram (int) | `ms` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). Bucket boundaries: 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 5000. |
| `otelcol_exporter_prometheusremotewrite_wal_writes` | Sum (int, monotonic) | `1` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). |
| `otelcol_exporter_prometheusremotewrite_wal_writes_failures` | Sum (int, monotonic) | `1` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). |
| `otelcol_exporter_prometheusremotewrite_written_exemplars` | Sum (int, monotonic) | `{exemplar}` | `exporter`; `endpoint` | Development stability.
