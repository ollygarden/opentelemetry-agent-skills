# Prometheus Remote Write Exporter

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_exporter_prometheusremotewrite_consumers` | Sum (non-monotonic) | `{consumer}` | `exporter`; `endpoint` | Development stability. Set once at exporter startup to the configured ceiling on parallel export requests — not a live worker count; the exporter spawns `min(ceiling, number of requests)` goroutines per batch. The ceiling is `remote_write_queue.num_consumers`, or the literal 5 if the `exporter.prometheusremotewritexporter.EnableMultipleWorkers` feature gate is enabled. `max_batch_request_parallelism` overrides both. A floor of 1 applies last, so `num_consumers: 0` reports 1. Both paths report 5 by default. |
| `otelcol_exporter_prometheusremotewrite_failed_translations` | Sum (monotonic) | `1` | `exporter`; `endpoint` | Development stability. Incremented each time the pmetric-to-Prometheus translation returns an error while batching metrics for export. |
| `otelcol_exporter_prometheusremotewrite_sent_batches` | Sum (monotonic) | `{batch}` | `exporter`; `endpoint` | Development stability. Incremented once per remote-write request batch sent, regardless of the outcome. |
| `otelcol_exporter_prometheusremotewrite_translated_time_series` | Sum (monotonic) | `1` | `exporter`; `endpoint` | Development stability. Incremented by the number of Prometheus time series produced by the OTel-to-Prometheus translation. |
| `otelcol_exporter_prometheusremotewrite_wal_bytes_read` | Sum (monotonic) | `By` | `exporter` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). |
| `otelcol_exporter_prometheusremotewrite_wal_bytes_written` | Sum (monotonic) | `By` | `exporter` | Development stability. Only emitted when the `wal` config block is set. |
