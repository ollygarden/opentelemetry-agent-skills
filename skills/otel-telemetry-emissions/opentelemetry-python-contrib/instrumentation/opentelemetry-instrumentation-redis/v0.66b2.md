# Redis instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| Redis command name (or configured database index when no command is present; `redis.search` for `FT.SEARCH`; `redis.create_index` for `FT.CREATE`) | CLIENT | `db.statement` or `db.query.text`; `db.system` or `db.system.name`; `db.redis.database_index`; `net.peer.name` or `server.address`; `net.peer.port` or `server.port`; `net.transport` or `network.transport`; `db.redis.args_length`; for `FT.CREATE`: `redis.create_index.index`, `redis.create_index.fields`; for `FT.SEARCH`: `redis.search.index`, `redis.search.query`, `redis.search.total`, and dynamic `redis.search.xdoc_<document>.<field>` | Sync and async command wrappers record spans when instrumentation is enabled. `OTEL_SEMCONV_STABILITY_OPT_IN` independently selects database and HTTP attributes: unset/default emits legacy names; `database` or `http` selects the corresponding stable names; `database/dup` or `http/dup` emits both sets. `db.redis.database_index` is legacy-only. `FT.CREATE` attributes are recorded in the synchronous command wrapper; `FT.SEARCH` result attributes are recorded there after command execution. Connection attributes are omitted when connection details are unavailable; Unix sockets omit the peer port. |
| Space-separated pipeline command names (or `redis` for an empty/invalid pipeline) | CLIENT | `db.statement` or `db.query.text`; `db.redis.pipeline_length`; `db.system` or `db.system.name`; `db.redis.database_index`; `net.peer.name` or `server.address`; `net.peer.port` or `server.port`; `net.transport` or `network.transport` | Sync and async pipelines, including cluster pipelines, record spans when instrumentation is enabled. `OTEL_SEMCONV_STABILITY_OPT_IN` selects legacy, stable, or duplicate database and HTTP attributes as described above; `db.redis.database_index` is legacy-only. Connection attributes are omitted when connection details are unavailable; Unix sockets omit the peer port. |
