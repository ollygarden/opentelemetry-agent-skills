# FastAPI instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<route>` (or HTTP method) | SERVER or INTERNAL | `http.route`; request attributes including `http.method`, `http.host`, `net.host.port`, `http.scheme`, `http.flavor`, `http.target`, `http.url`, `http.user_agent`, `http.server_name`, `net.peer.ip`, `net.peer.port`; response `http.status_code`; captured request/response headers when configured | Server span for HTTP and websocket scopes; excluded URLs and `OTEL_PYTHON_FASTAPI_EXCLUDED_URLS` suppress it. |
| `<server span name> <scope type> receive` | INTERNAL | `type`; websocket status code when applicable | Receive spans are emitted for each ASGI receive event. |
| `<server span name> <scope type> send` | INTERNAL | `type`; HTTP/websocket status code when applicable | Send spans are emitted for each ASGI send event. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.active_requests` | UpDownCounter | `requests` | HTTP server request dimensions (`http.method`, `http.host`, `net.host.port`, `http.scheme`, `http.flavor`, `http.server_name`, `net.peer.*`) | HTTP scopes only. |
| `http.server.duration` | Histogram | `ms` | Server request dimensions plus `http.status_code`, `http.target` | HTTP scopes only. |
