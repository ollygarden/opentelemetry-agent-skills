# FastAPI instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method> <route>` (route alone for websocket; method alone when unmatched) | SERVER or INTERNAL (with an active span) | Legacy: `http.scheme`, `http.host`, `net.host.port`, `http.flavor`, `http.target`, `http.url`, `http.method`, `http.server_name`, `http.user_agent`, `net.peer.ip`, `net.peer.port`, `http.route`, `http.status_code`. Stable: `url.scheme`, `server.address`, `server.port`, `network.protocol.version`, `url.path`, `url.query`, `http.request.method`, `http.request.method_original`, `user_agent.original`, `client.address`, `client.port`, `http.route`, `http.response.status_code`, `error.type`; configured `http.request.header.*` and `http.response.header.*` | Legacy is the default; `OTEL_SEMCONV_STABILITY_OPT_IN=http` selects stable attributes and `http/dup` emits both. Attributes are conditional on available request/response data. Header attributes require `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SERVER_REQUEST` / `_RESPONSE`; sanitization via `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SANITIZE_FIELDS`. |
| `<server span name> <http|websocket> receive` | INTERNAL | `asgi.event.type`; legacy `http.status_code` or stable `http.response.status_code` for websocket receive | Suppressed when `exclude_spans` includes `receive`. |
| `<server span name> <http|websocket> send` | INTERNAL | `asgi.event.type`; legacy `http.status_code` or stable `http.response.status_code` when a status is available | Suppressed when `exclude_spans` includes `send`. |
| `BackgroundTask <function name>` | INTERNAL | No built-in attributes | Created when an instrumented Starlette background task runs; function name falls back to the callable class name. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.duration` | Histogram | `ms` | Legacy HTTP duration attributes, including method, status code, and parameterized `http.target` when a route is available | HTTP requests only; default or `OTEL_SEMCONV_STABILITY_OPT_IN=http/dup`. |
| `http.server.request.duration` | Histogram | `s` | `http.request.method`, `http.response.status_code`, `http.route`, `network.protocol.version`, `url.scheme`, `error.type` (when available) | HTTP requests only; `OTEL_SEMCONV_STABILITY_OPT_IN=http` or `http/dup`. |
| `http.server.request.size` | Histogram | `By` | Same legacy duration attributes as `http.server.duration` | Default or `http/dup`; HTTP request `Content-Length` must be a parseable integer. |
| `http.server.response.size` | Histogram | `By` | Same legacy duration attributes as `http.server.duration` | Default or `http/dup`; HTTP response `Content-Length` must be a parseable, nonzero integer. |
| `http.server.request.body.size` | Histogram | `By` | Same stable duration attributes as `http.server.request.duration` | `http` or `http/dup`; HTTP request `Content-Length` must be a parseable integer. |
| `http.server.response.body.size` | Histogram | `By` | Same stable duration attributes as `http.server.request.duration` | `http` or `http/dup`; HTTP response `Content-Length` must be a parseable, nonzero integer. |
| `http.server.active_requests` | UpDownCounter | `{request}` | Legacy active-request attributes by default; stable `http.request.method`, `url.scheme` with `http`; both with `http/dup` | HTTP requests only. |
