# FastAPI instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| Matched FastAPI route path (fallback HTTP method; blank for unmatched websocket) | SERVER | `http.scheme`, `http.host`, `net.host.port`, `http.flavor`, `http.target`, `http.url`, `http.method`, `http.server_name`, `http.user_agent`, `net.peer.ip`, `net.peer.port`, `http.route`, `http.status_code`; configured `http.request.header.*` and `http.response.header.*` | Header attributes require `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SERVER_REQUEST` / `_RESPONSE`; sanitization via `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SANITIZE_FIELDS`. |
| `<server span name> <http|websocket> receive` | INTERNAL | `type`; `http.status_code` for websocket receive | - |
| `<server span name> <http|websocket> send` | INTERNAL | `type`, `http.status_code` | - |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.duration` | Histogram | `ms` | HTTP duration attributes including method, status code, and parameterized `http.target` when route is available | HTTP requests only. |
| `http.server.active_requests` | UpDownCounter | `requests` | Active-request-count attributes derived from request attributes | HTTP requests only. |
