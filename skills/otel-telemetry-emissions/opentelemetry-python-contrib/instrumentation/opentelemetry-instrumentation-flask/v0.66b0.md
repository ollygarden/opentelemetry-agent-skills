# Flask instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method> <Flask URL rule>` (or WSGI method/path fallback) | SERVER (or INTERNAL when a valid parent span suppresses server-span creation) | Legacy mode: `http.method`, `http.server_name`, `http.scheme`, `http.host`, `http.target` or `http.url`, `http.flavor`, `http.user_agent`, `net.host.name`, `net.host.port`, `net.peer.ip`, `net.peer.port`, `net.peer.name`, `http.status_code`; HTTP mode: `http.request.method`, `http.request.method_original` (when normalized), `url.scheme`, `url.path`, `url.query`, `network.protocol.version`, `server.address`, `server.port`, `client.address`, `client.port`, `user_agent.original`, `user_agent.synthetic.type`, `http.response.status_code`; `http.route` when a Flask rule matches; configured `http.request.header.<name>` and `http.response.header.<name>` | Legacy/HTTP attributes are selected by `OTEL_SEMCONV_STABILITY_OPT_IN` for HTTP (`default`, `http`, or `http/dup`). Header attributes require the corresponding `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SERVER_REQUEST`/`...RESPONSE` setting. `error.type` is added for HTTP-mode error responses/exceptions. Requests matching excluded URLs do not emit the span. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.duration` | Histogram | `ms` | Legacy: `http.method`, `http.host`, `http.scheme`, `http.status_code`, `http.flavor`, `http.server_name`, `net.host.name`, `net.host.port`; `http.target` is used for Flask route timing | Emitted when legacy HTTP semantic conventions are reported (`OTEL_SEMCONV_STABILITY_OPT_IN` unset/`default` or `http/dup`). |
| `http.server.request.duration` | Histogram | `s` | `error.type`, `http.request.method`, `http.response.status_code`, `http.route`, `network.protocol.version`, `url.scheme` | Emitted when stable HTTP semantic conventions are reported (`OTEL_SEMCONV_STABILITY_OPT_IN=http` or `http/dup`). |
| `http.server.active_requests` | UpDownCounter | `requests` / `{request}` | Legacy: `http.method`, `http.host`, `http.scheme`, `http.flavor`, `http.server_name`; HTTP mode: `http.request.method`, `url.scheme` | Recorded at request start/end. Attribute set follows `OTEL_SEMCONV_STABILITY_OPT_IN`; the HTTP-mode instrument is created by the HTTP semantic-convention helper. |
