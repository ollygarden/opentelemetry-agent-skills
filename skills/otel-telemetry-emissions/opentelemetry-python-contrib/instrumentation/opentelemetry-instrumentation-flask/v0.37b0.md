# Flask Instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| Flask URL rule (fallback to WSGI default span name) | SERVER (or INTERNAL when an ambient span is active) | `http.*` request/response attributes collected by WSGI; `http.route`; optionally `http.request.header.*`, `http.response.header.*` | Excluded URLs are not traced; header capture is controlled by `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SERVER_REQUEST` / `_RESPONSE`; sanitization by `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SANITIZE_FIELDS` |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.active_requests` | UpDownCounter | requests | HTTP request attributes parsed by WSGI | |
| `http.server.duration` | Histogram | ms | HTTP request/duration attributes parsed by WSGI; includes HTTP status code when available | |
