# opentelemetry-instrumentation-requests

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{HTTP method}` (or `HTTP` for non-standard methods) | CLIENT | `http.method`, `http.url`, `http.status_code` (when a response is available), `user_agent.original` (when a User-Agent is present), `user_agent.synthetic.type` (when the User-Agent is recognized as synthetic), `http.request.header.<normalized_header>` (configured request headers), `http.response.header.<normalized_header>` (configured response headers) | Legacy HTTP semantic conventions are reported by default, or with `OTEL_SEMCONV_STABILITY_OPT_IN=http/dup`; header attributes require `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_CLIENT_REQUEST` or `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_CLIENT_RESPONSE`; header values are sanitized when matched by `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SANITIZE_FIELDS`. |
| `{HTTP method}` (or `HTTP` for non-standard methods) | CLIENT | `http.request.method`, `url.full`, `server.address`, `network.peer.address`, `http.response.status_code` (when a response is available), `network.protocol.version` (when response raw protocol version is available), `server.port`, `network.peer.port`, `error.type` (on request/HTTP errors), `user_agent.original` (when a User-Agent is present), `user_agent.synthetic.type` (when recognized), `http.request.header.<normalized_header>`, `http.response.header.<normalized_header>` | New HTTP semantic conventions are reported when `OTEL_SEMCONV_STABILITY_OPT_IN=http`; also reported alongside legacy conventions with `OTEL_SEMCONV_STABILITY_OPT_IN=http/dup`. Header attributes require the corresponding capture environment variable; sanitization uses `OTEL_INSTRUMENTATION_HTTP_CAPTURE_HEADERS_SANITIZE_FIELDS`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.client.duration` | Histogram | ms | `http.method`, `http.scheme`, `http.host`, `net.peer.name`, `net.peer.port`, `http.status_code` (when a response is available), `http.flavor` (when response raw protocol version is available) | Legacy HTTP semantic conventions; emitted by default or with `OTEL_SEMCONV_STABILITY_OPT_IN=http/dup`. |
| `http.client.request.duration` | Histogram | s | `http.request.method`, `server.address`, `server.port`, `http.response.status_code` (when a response is available), `network.protocol.version` (when response raw protocol version is available), `error.type` (on request/HTTP errors) | Emitted with `OTEL_SEMCONV_STABILITY_OPT_IN=http` or `http/dup`. |
