# Psycopg2

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| SQL operation name (first SQL token; database/system fallback, also for comment-only or whitespace-only statements) | CLIENT | `db.system`/`db.system.name`, `db.name`/`db.namespace`, `db.statement`/`db.query.text`, `db.user` (legacy and `database/dup` only; no new-mode replacement), `net.peer.name`/`server.address`, `net.peer.port`/`server.port`; optionally `db.statement.parameters` | One span is emitted for `execute`, `executemany`, and `callproc`. Attribute naming follows the database semantic-convention mode selected by `OTEL_SEMCONV_STABILITY_OPT_IN` (`database`: new names only; `database/dup`: legacy and new; otherwise legacy). `db.statement.parameters` requires `capture_parameters=True`. SQL comments are included in statement/query attributes only with `enable_commenter=True` and `enable_attribute_commenter=True`, which are accepted by both `instrument()` and `instrument_connection()`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.system.name`, `db.namespace` (when database is set), `db.operation.name`, `server.address`, `server.port`, `error.type` (on error) | Emitted only when `OTEL_SEMCONV_STABILITY_OPT_IN` includes `database` or `database/dup`. Recorded for each operation; `error.type` is present only when execution raises. |
| `db.client.response.returned_rows` | Histogram | `{row}` | `db.system.name`, `db.namespace` (when database is set), `db.operation.name`, `server.address`, `server.port`, `error.type` (on error) | Emitted only when `OTEL_SEMCONV_STABILITY_OPT_IN` includes `database` or `database/dup`; recorded only for successful operations with a non-negative integer row count. |
