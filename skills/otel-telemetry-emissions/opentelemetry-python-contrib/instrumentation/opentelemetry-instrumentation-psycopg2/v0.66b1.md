# Psycopg2

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| SQL operation name (first SQL token; database/system fallback, including comment-only or whitespace-only statements) | CLIENT | `db.system`/`db.system.name`, `db.name`/`db.namespace`, `db.statement`/`db.query.text`, `db.user` (legacy and `database/dup` only), `net.peer.name`/`server.address`, `net.peer.port`/`server.port`; optionally `db.statement.parameters` | One span for `execute`, `executemany`, and `callproc`. Attribute naming follows `OTEL_SEMCONV_STABILITY_OPT_IN` (`database`: new names; `database/dup`: both; otherwise legacy). Parameters require `capture_parameters=True`; SQL comments in span attributes require `enable_commenter=True` and `enable_attribute_commenter=True`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.system.name`, `db.namespace`, `db.operation.name`, `server.address`, `server.port`, `error.type` | Emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` includes `database` or `database/dup`; `error.type` only on errors. |
| `db.client.response.returned_rows` | Histogram | `{row}` | `db.system.name`, `db.namespace`, `db.operation.name`, `server.address`, `server.port`, `error.type` | Emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` includes `database` or `database/dup`; successful operations with a non-negative integer row count only. |
