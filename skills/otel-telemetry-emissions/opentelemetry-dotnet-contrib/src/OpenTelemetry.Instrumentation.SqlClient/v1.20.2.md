# SqlClient

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| SQL operation name (database namespace, server address, or `microsoft.sql_server`; sanitized query summary or `EXECUTE <procedure>` when available) | Client | `db.system.name`, `db.namespace`, `server.address`, `server.port`, `db.query.text`, `db.query.summary`, `db.operation.name`, `db.stored_procedure.name`, `db.query.parameter.{key}`, `db.response.returned_rows`, `db.response.status_code`, `error.type` | Connection and query attributes are conditional on available command/connection data; query text is sanitized. `db.query.parameter.{key}` is opt-in via `OTEL_DOTNET_EXPERIMENTAL_SQLCLIENT_ENABLE_TRACE_DB_QUERY_PARAMETERS` (default false); `db.response.returned_rows` is opt-in via `OTEL_DOTNET_EXPERIMENTAL_SQLCLIENT_ENABLE_RECORD_RETURNED_ROWS` (default false; .NET only and only when row statistics are available). `error.type` and `db.response.status_code` are failure-only; exception events require `RecordException` (default false; .NET only). .NET Framework activity collection is driven by SqlClient EventSource; SqlClient runtime/library behavior is outside this repository. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.system.name`, `db.namespace`, `server.address`, `server.port`, `db.operation.name`, `db.stored_procedure.name`, `db.query.summary`, `db.response.status_code`, `error.type` | `db.query.summary` when available for text or stored-procedure commands. Attributes depend on command type, connection data, and failure. |
