# Confluent Kafka instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `send {topic}` (or `send` when unavailable) | Producer | messaging.destination.name, messaging.operation.name, messaging.operation.type, messaging.system.name, messaging.destination.partition.id, messaging.client.id, kafka.message.key, kafka.message.tombstone, kafka.cluster.id, error.type | TracerProviderBuilder.AddKafkaProducerInstrumentation/AddKafkaConsumerInstrumentation enables tracing; default off. Partition, message key, tombstone, and cluster ID are conditional; `error.type` is set on failures. |
| `poll {topic}` (or `poll` when unavailable) | Client | messaging.operation.name, messaging.operation.type, messaging.system.name, messaging.consumer.group.name, messaging.destination.name, messaging.destination.partition.id, messaging.client.id, kafka.offset, kafka.message.key, kafka.message.tombstone, kafka.cluster.id, error.type | TracerProviderBuilder.AddKafkaProducerInstrumentation/AddKafkaConsumerInstrumentation enables tracing; default off. Topic, partition, consumer group, message key, tombstone, and cluster ID are conditional; `error.type` is set on failures. |
| `process {topic}` (or `process` when unavailable) | Consumer | messaging.operation.name, messaging.operation.type, messaging.system.name, messaging.consumer.group.name, messaging.destination.name, messaging.destination.partition.id, messaging.client.id, kafka.offset, kafka.message.key, kafka.message.tombstone, kafka.cluster.id, error.type | Created only by `ConsumeAndProcessMessageAsync` on a consumer built by `InstrumentedConsumerBuilder` (any other consumer throws `ArgumentException`), when it receives a non-EOF message; ordinary `Consume` calls do not create it. The span needs a listener on the `OpenTelemetry.Instrumentation.ConfluentKafka` source but not the consumer trace flag, so `AddSource` with that name or `AddKafkaProducerInstrumentation` enables it without `AddKafkaConsumerInstrumentation`. Topic, partition, consumer group, message key, tombstone, and cluster ID are conditional; `error.type` is set when the handler throws. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `messaging.client.operation.duration` | Histogram | `s` | messaging.operation.name, messaging.operation.type, messaging.system.name, messaging.destination.name, messaging.destination.partition.id, messaging.consumer.group.name, error.type | EnableMetrics defaults to false; metrics require explicit opt-in. Destination, partition, consumer group, and error type depend on the operation and available data. |
| `messaging.client.sent.messages` | Counter | `{message}` | messaging.operation.name, messaging.operation.type, messaging.system.name, messaging.destination.name, messaging.destination.partition.id, error.type | EnableMetrics defaults to false; metrics require explicit opt-in. Partition and error type are conditional. |
| `messaging.client.consumed.messages` | Counter | `{message}` | messaging.operation.name, messaging.operation.type, messaging.system.name, messaging.destination.name, messaging.destination.partition.id, messaging.consumer.group.name, error.type | EnableMetrics defaults to false; metrics require explicit opt-in. Incremented when `Consume` returns a non-EOF message, and also when `Consume` throws a `ConsumeException` that carries a consumer record (with `error.type`; the exception is rethrown, so the application does not receive the message); destination, partition, consumer group, and error type depend on available data. |
