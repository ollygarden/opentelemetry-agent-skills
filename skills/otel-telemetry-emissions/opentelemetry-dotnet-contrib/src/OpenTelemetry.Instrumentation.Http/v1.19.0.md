# HttpClient instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| HTTP method (or `HTTP` for an unrecognized method) | CLIENT | http.request.method, http.request.method_original (when normalized), server.address, server.port, url.full, network.protocol.version, http.response.status_code, error.type | Attributes shown are populated by package enrichment before .NET 9; .NET 9+ supplies native trace attributes. `RecordException` adds an exception event; URL query redaction can be disabled by `DisableUrlQueryRedaction` or `OTEL_DOTNET_EXPERIMENTAL_HTTPCLIENT_DISABLE_URL_QUERY_REDACTION`. |

## Metrics

The row below describes the package-owned duration metric on .NET Framework, .NET 6, and .NET 7. On .NET 8+, `AddHttpClientInstrumentation` subscribes to the native `System.Net.Http` and `System.Net.NameResolution` meters, including additional runtime-defined instruments; consult the pinned package README and the installed runtime documentation for those emissions.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| http.client.request.duration | Histogram | s | http.request.method, server.address, url.scheme, server.port, network.protocol.version, http.response.status_code, error.type | HTTP client metrics instrumentation enabled; response/error attributes only when available. |
