# ASP.NET Core Instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| Microsoft.AspNetCore.Hosting.HttpRequestIn | SERVER | http.request.method, http.request.method_original, http.response.status_code, http.route, url.scheme, url.path, url.query, server.address, server.port, network.protocol.version, network.peer.address, network.peer.port, user_agent.original, error.type, rpc.response.status_code; gRPC status attributes | Created from the ASP.NET Core request activity, or as a sibling activity when a non-`TraceContextPropagator` default propagator extracts a parent that differs from the framework activity's parent. With `OTEL_DOTNET_EXPERIMENTAL_ASPNETCORE_ENABLE_NEW_ROOT_SPAN=true` (default false; .NET 8+ builds only), a request with a parent starts a new root activity linked to that parent instead. Attributes depend on request/framework data; query redaction and enrichment are configurable. `RecordException` enables exception events; `Filter` can suppress instrumentation. ActivitySource scope: `Microsoft.AspNetCore` on .NET 7+; on runtimes below .NET 7 (netstandard2.0 build) the listener assigns `OpenTelemetry.Instrumentation.AspNetCore` to the request activity, so scope filters must cover both names. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| http.server.request.duration | Histogram | s | network.protocol.version, url.scheme, http.response.status_code, http.request.method, error.type | Package-owned metric, recorded on request stop. `error.type` is the captured exception type name, or the status code when the status resolves to an error (5xx). Instrument is compiled only for non-`NET` targets; on .NET 8+ the builder extension also subscribes to framework meters, including `Microsoft.AspNetCore.Hosting`. Those framework instruments are emitted by ASP.NET Core runtime outside this repository. Meter scope: `OpenTelemetry.Instrumentation.AspNetCore`. |
