# StackExchange.Redis instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `command.Command` (for example, `GET`); falls back to `OpenTelemetry.Instrumentation.StackExchangeRedis.Execute` when empty | CLIENT | `db.system` (`redis`) or `db.system.name` (`redis`); conditionally `db.redis.database_index`, `db.statement`; conditionally `db.operation.name`, `db.namespace`, `db.query.text`; endpoint-dependent `server.address`, `server.port`, `network.peer.address`, `network.peer.port` | `OTEL_SEMCONV_STABILITY_OPT_IN` defaults to the old database conventions; `database` selects new attributes and `database/dup` emits both. `SetVerboseDatabaseStatements` defaults to false and enriches statement/query text when enabled. Endpoint attributes depend on endpoint type: IP emits server and network fields, DNS emits server fields, and Unix sockets emit addresses only on supported .NET targets. A `Filter` callback returning false or throwing suppresses the span. |
