# OpenTelemetry .NET Runtime Instrumentation

## Metrics

The table lists the package-owned instruments from `RuntimeMetrics` (meter `OpenTelemetry.Instrumentation.Runtime`). On .NET 9+ (the `net10.0` build, or any build when `Environment.Version.Major >= 9`), `AddRuntimeInstrumentation` only calls `AddMeter("System.Runtime")` and does not instantiate `RuntimeMetrics`, so none of these `process.runtime.dotnet.*` metrics are emitted. The runtime's built-in `System.Runtime` meter emits differently named metrics instead, for example `dotnet.gc.collections` with `gc.heap.generation` rather than `process.runtime.dotnet.gc.collections.count` with `generation`. Those instruments are defined by the .NET runtime outside this repository and are not verified here; the pinned README points to https://learn.microsoft.com/en-us/dotnet/core/diagnostics/built-in-metrics-runtime for their names and attributes.
