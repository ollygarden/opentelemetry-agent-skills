# OpenTelemetry .NET Runtime Instrumentation

## Metrics

The table lists the package-owned instruments from `RuntimeMetrics` (meter `OpenTelemetry.Instrumentation.Runtime`). This version targets `net11.0`, `net10.0`, `netstandard2.0` and `net462`, and compiles `RuntimeMetrics` only for `netstandard2.0` and `net462` (`#if !NET`). Its nested `#if NET` instruments (GC allocation, memory and pause, JIT, lock contention, thread-pool and timer metrics) are therefore never compiled, so only the four metrics below exist, on .NET Framework and on .NET 8 (which loads the `netstandard2.0` build). On .NET 9+ (the `net10.0`/`net11.0` builds, or the `netstandard2.0` build when `Environment.Version.Major >= 9`), `AddRuntimeInstrumentation` only calls `AddMeter("System.Runtime")` and does not instantiate `RuntimeMetrics`, so none of these `process.runtime.dotnet.*` metrics are emitted. The runtime's built-in `System.Runtime` meter emits differently named metrics instead, for example `dotnet.gc.collections` with `gc.heap.generation` rather than `process.runtime.dotnet.gc.collections.count` with `generation`. Those instruments are defined by the .NET runtime outside this repository and are not verified here; the pinned README points to https://learn.microsoft.com/en-us/dotnet/core/diagnostics/built-in-metrics-runtime for their names and attributes.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `process.runtime.dotnet.exceptions.count` | Counter | - | - | First-chance managed exceptions; emitted after at least one exception since initialization. Emitted on runtimes below .NET 9, including .NET Framework; not emitted on .NET 9+. |
| `process.runtime.dotnet.gc.collections.count` | ObservableCounter | - | generation (`gen0`, `gen1`, `gen2`) | Emitted on runtimes below .NET 9, including .NET Framework; not emitted on .NET 9+. |
| `process.runtime.dotnet.gc.objects.size` | ObservableUpDownCounter | bytes | - | Emitted on runtimes below .NET 9, including .NET Framework; not emitted on .NET 9+. |
| `process.runtime.dotnet.assemblies.count` | ObservableUpDownCounter | - | - | Emitted on runtimes below .NET 9, including .NET Framework; not emitted on .NET 9+. |
