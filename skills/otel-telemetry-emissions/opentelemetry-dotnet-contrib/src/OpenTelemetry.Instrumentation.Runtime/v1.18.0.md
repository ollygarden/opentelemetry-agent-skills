# OpenTelemetry .NET Runtime Instrumentation

## Metrics

The table below describes the package-owned metrics used before .NET 9. On .NET 9+, `AddRuntimeInstrumentation` subscribes to the native `System.Runtime` meter and does not instantiate `RuntimeMetrics`; the metric names and attributes come from the installed runtime. See the pinned package README for that runtime telemetry boundary.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `process.runtime.dotnet.exceptions.count` | Counter | {exception} | - | First-chance managed exceptions; emitted after at least one exception since initialization. |
| `process.runtime.dotnet.gc.collections.count` | Counter | {collection} | generation | - |
| `process.runtime.dotnet.gc.objects.size` | UpDownCounter | bytes | - | - |
| `process.runtime.dotnet.gc.allocations.size` | Counter | bytes | - | - |
| `process.runtime.dotnet.gc.committed_memory.size` | UpDownCounter | bytes | - | Value unavailable until a GC has occurred. |
| `process.runtime.dotnet.gc.heap.size` | UpDownCounter | bytes | generation | Value unavailable until a GC has occurred. |
| `process.runtime.dotnet.gc.heap.fragmentation.size` | UpDownCounter | bytes | generation | Value unavailable until a GC has occurred. |
| `process.runtime.dotnet.gc.duration` | Counter | ns | - | - |
| `process.runtime.dotnet.jit.il_compiled.size` | Counter | bytes | - | - |
| `process.runtime.dotnet.jit.methods_compiled.count` | Counter | {method} | - | - |
| `process.runtime.dotnet.jit.compilation_time` | Counter | ns | - | - |
| `process.runtime.dotnet.monitor.lock_contention.count` | Counter | {count} | - | - |
| `process.runtime.dotnet.thread_pool.threads.count` | UpDownCounter | {thread} | - | - |
| `process.runtime.dotnet.thread_pool.completed_items.count` | Counter | {item} | - | - |
| `process.runtime.dotnet.thread_pool.queue.length` | UpDownCounter | {item} | - | - |
| `process.runtime.dotnet.timer.count` | UpDownCounter | {timer} | - | - |
| `process.runtime.dotnet.assemblies.count` | UpDownCounter | {assembly} | - | - |
