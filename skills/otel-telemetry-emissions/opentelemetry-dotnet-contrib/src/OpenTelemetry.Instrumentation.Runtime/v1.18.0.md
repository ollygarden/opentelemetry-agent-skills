# OpenTelemetry .NET Runtime Instrumentation

## Metrics

The table lists the package-owned instruments from `RuntimeMetrics` (meter `OpenTelemetry.Instrumentation.Runtime`). This version targets `net10.0`, `net8.0`, `netstandard2.0` and `net462`. In every build, `AddRuntimeInstrumentation` checks `Environment.Version.Major >= 9` at runtime; on .NET 9+ (including every app that loads the `net10.0` build) it only calls `AddMeter("System.Runtime")` and does not instantiate `RuntimeMetrics`, so none of these `process.runtime.dotnet.*` metrics are emitted. The runtime's built-in `System.Runtime` meter emits differently named metrics instead, for example `dotnet.gc.collections` with `gc.heap.generation` rather than `process.runtime.dotnet.gc.collections.count` with `generation`. Those instruments are defined by the .NET runtime outside this repository and are not verified here; the pinned README points to https://learn.microsoft.com/en-us/dotnet/core/diagnostics/built-in-metrics-runtime for their names and attributes.

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `process.runtime.dotnet.exceptions.count` | Counter | - | - | First-chance managed exceptions; emitted after at least one exception since initialization. |
| `process.runtime.dotnet.gc.collections.count` | ObservableCounter | - | generation (`gen0`, `gen1`, `gen2`) | - |
| `process.runtime.dotnet.gc.objects.size` | ObservableUpDownCounter | bytes | - | - |
| `process.runtime.dotnet.gc.allocations.size` | ObservableCounter | bytes | - | .NET 8 only. |
| `process.runtime.dotnet.gc.committed_memory.size` | ObservableUpDownCounter | bytes | - | .NET 8 only. Value unavailable until a GC has occurred. |
| `process.runtime.dotnet.gc.heap.size` | ObservableUpDownCounter | bytes | generation (`gen0`, `gen1`, `gen2`, `loh`, `poh`) | .NET 8 only. Value unavailable until a GC has occurred. |
| `process.runtime.dotnet.gc.heap.fragmentation.size` | ObservableUpDownCounter | bytes | generation (`gen0`, `gen1`, `gen2`, `loh`, `poh`) | .NET 8 only. Value unavailable until a GC has occurred. |
| `process.runtime.dotnet.gc.duration` | ObservableCounter | ns | - | .NET 8 only. |
| `process.runtime.dotnet.jit.il_compiled.size` | ObservableCounter | bytes | - | .NET 8 only. |
| `process.runtime.dotnet.jit.methods_compiled.count` | ObservableCounter | - | - | .NET 8 only. |
| `process.runtime.dotnet.jit.compilation_time` | ObservableCounter | ns | - | .NET 8 only. |
| `process.runtime.dotnet.monitor.lock_contention.count` | ObservableCounter | - | - | .NET 8 only. |
| `process.runtime.dotnet.thread_pool.threads.count` | ObservableUpDownCounter | - | - | .NET 8 only. |
| `process.runtime.dotnet.thread_pool.completed_items.count` | ObservableCounter | - | - | .NET 8 only. |
| `process.runtime.dotnet.thread_pool.queue.length` | ObservableUpDownCounter | - | - | .NET 8 only. |
| `process.runtime.dotnet.timer.count` | ObservableUpDownCounter | - | - | .NET 8 only. |
| `process.runtime.dotnet.assemblies.count` | ObservableUpDownCounter | - | - | - |

Rows marked `.NET 8 only` are inside `#if NET`, so they are compiled into the `net10.0` and `net8.0` builds only. The `net10.0` build always takes the .NET 9+ path, so these metrics are emitted only on .NET 8; they are not emitted on .NET Framework (`net462` build), on runtimes that load the `netstandard2.0` build, or on .NET 9+. The other rows are emitted on every runtime below .NET 9, including .NET Framework.
