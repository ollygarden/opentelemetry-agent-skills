# GrpcNetClient instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| gRPC method (activity operation name) | CLIENT | rpc.system=grpc; rpc.method; rpc.method_original when method is `other`; server.address and server.port when request URI exists; network.peer.address and network.peer.port for IP hosts; rpc.response.status_code when gRPC status is available; error.type on error | Existing `Grpc.Net.Client` activity is enriched when `Activity.IsAllDataRequested` and the request filter accepts it. The filter defaults to accept; `SuppressInstrumentation` and sampler decisions can prevent enrichment. The instrumentation assigns `OpenTelemetry.Instrumentation.GrpcNetClient` as the ActivitySource; the activity originates in `Grpc.Net.Client`. Request and response enrichment callbacks can add user-defined attributes. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| NullPayload | handlerName; eventName | EventSource `OpenTelemetry-Instrumentation-Grpc`, event ID 1, Warning; emitted when the start event payload has no request. |
| EnrichmentException | exception | EventSource `OpenTelemetry-Instrumentation-Grpc`, event ID 2, Error; emitted when request or response enrichment throws. |
| UnknownErrorProcessingEvent | handlerName; eventName; ex | EventSource `OpenTelemetry-Instrumentation-Grpc`, event ID 3, Error. |
| RequestFilterException | exception | EventSource `OpenTelemetry-Instrumentation-Grpc`, event ID 4, Error; emitted when the request filter throws (and the request is not collected). |
| RequestIsFilteredOut | eventName | EventSource `OpenTelemetry-Instrumentation-Grpc`, event ID 5, Verbose; emitted when the request filter rejects the request. |
