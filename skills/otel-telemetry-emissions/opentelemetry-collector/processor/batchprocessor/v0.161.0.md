# Batch processor

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_processor_batch_batch_send_size` | Histogram (int) | `{unit}` | `processor` | Recorded after each successfully exported batch; counts telemetry units (spans, metric data points, or log records). |
| `otelcol_processor_batch_batch_send_size_bytes` | Histogram (int) | `By` | `processor` | Recorded after each successfully exported batch; only calculated and emitted when the instrument is enabled (detailed telemetry level). |
| `otelcol_processor_batch_batch_size_trigger_send` | Counter (int) | `{time}` | `processor` | Recorded when a batch is successfully sent because the configured batch size was reached. |
| `otelcol_processor_batch_metadata_cardinality` | Observable UpDownCounter (int) | `{combination}` | `processor` | Asynchronously observes the number of distinct metadata value combinations currently being processed. |
| `otelcol_processor_batch_timeout_trigger_send` | Counter (int) | `{time}` | `processor` | Recorded when a batch is successfully sent because the timeout expired, or when a pending batch is flushed during shutdown. |
