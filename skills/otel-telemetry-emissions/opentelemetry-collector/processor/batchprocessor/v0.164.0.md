# Batch processor

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_processor_batch_batch_send_size` | Histogram (int) | `{unit}` | `processor` | Recorded after each successfully exported batch; counts telemetry units (spans, metric data points, or log records). |
| `otelcol_processor_batch_batch_send_size_bytes` | Histogram (int) | `By` | `processor` | Only available at detailed telemetry level. |
| `otelcol_processor_batch_batch_size_trigger_send` | Counter (int) | `{time}` | `processor` | Recorded when a batch is successfully sent from the item-arrival path: when `send_batch_size` is reached, or for every arriving item when `timeout` or `send_batch_size` is 0 (no timer), so it can increase below `send_batch_size`. |
| `otelcol_processor_batch_metadata_cardinality` | Observable UpDownCounter (int) | `{combination}` | `processor` | Asynchronously observes the number of distinct metadata value combinations currently being processed. |
| `otelcol_processor_batch_timeout_trigger_send` | Counter (int) | `{time}` | `processor` | Recorded when a pending batch is successfully sent because the timeout expired, and also when shutdown flushes a pending batch before its timer expires. |

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `Sender failed` | `error` | Emitted at WARN level when the next consumer returns an error for a batch; no batch metrics are recorded for that send. |
