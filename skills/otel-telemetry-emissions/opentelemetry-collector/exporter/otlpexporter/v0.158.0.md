# OTLP exporter

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `exporter/<exporter ID>/<signal>` | INTERNAL | `exporter=<exporter ID>`; `data_type=<traces\|metrics\|logs\|profiles>` | Created by exporterhelper for each export request; includes queue links when queued. Sets `items.sent` and `items.failed`; errors set span status to ERROR. |
| `exporter/enqueue` | INTERNAL | - | Created when a sending queue is configured, for each queue offer. |
