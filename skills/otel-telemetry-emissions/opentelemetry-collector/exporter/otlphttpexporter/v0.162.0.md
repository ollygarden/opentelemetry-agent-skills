# OTLP HTTP Exporter

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `exporter/<exporter-id>/<signal>` | Internal | `exporter`, `data_type`, `items.sent`, `items.failed` | Emitted by exporterhelper for traces, metrics, logs, and profiles; profile spans are used when the alpha profiles signal is enabled. |
| `exporter/enqueue` | Internal | - | Emitted when the sending queue is enabled; one span per queue offer. |
