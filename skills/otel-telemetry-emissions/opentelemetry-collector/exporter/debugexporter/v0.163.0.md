# Debug Exporter

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `Traces` | `resource spans`; `spans` | Summary is logged for every received batch; marshaled payload is additionally logged when verbosity is normal or detailed (default: basic). Sampling uses sampling_initial (default 2) and sampling_thereafter (default 1; effectively disabled) on internal and custom loggers. |
| `Metrics` | `resource metrics`; `metrics`; `data points` | Summary is logged for every received batch; marshaled payload is additionally logged when verbosity is normal or detailed (default: basic). | `Logs` | `resource logs`; `log records` | Summary is logged for every received batch; marshaled payload is additionally logged when verbosity is normal or detailed (default: basic).
