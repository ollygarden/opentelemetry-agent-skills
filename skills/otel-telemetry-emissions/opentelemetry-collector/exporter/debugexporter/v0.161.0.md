## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `Traces` | `resource spans`; `spans` | INFO summary emitted for each received trace batch. With `verbosity: normal` or `detailed`, an additional INFO message contains the marshaled input; output is subject to `sampling_initial` and `sampling_thereafter`. |
