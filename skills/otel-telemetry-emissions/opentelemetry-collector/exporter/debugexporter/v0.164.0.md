# Debug Exporter

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `Traces` | `resource spans`; `spans` | INFO summary for each received trace batch. With `verbosity: normal` or `detailed` (default `basic`), an additional INFO message contains the marshaled payload. Neither is emitted when the collector's internal logger level is above INFO (`use_internal_logger: true`, the default); the custom logger used with `use_internal_logger: false` is fixed at INFO. Both messages pass through a per-second sampler: `sampling_initial` (default 2) entries per message, then every `sampling_thereafter`-th (default 1, so the defaults drop nothing). |
