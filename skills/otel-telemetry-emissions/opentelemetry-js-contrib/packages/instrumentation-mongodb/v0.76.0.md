# MongoDB Instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{db.operation.name} {db.collection.name}`, or whichever part is present (`mongodb` when both are absent) | CLIENT | `db.system.name`, `db.namespace`, `db.operation.name`, `db.collection.name`, `server.address`, `server.port`, `db.query.text` | MongoDB v3 `insert`, `update`, `remove`, `command`, `query`, and `getMore`; MongoDB v4–7 driver commands excluding `ismaster` and `hello`. An unrecognized v3 command has no `db.operation.name`, so e.g. `ping` on `admin.$cmd` is named `$cmd`. Span creation requires a parent span by default (`requireParentSpan=true`); set false to allow root spans. `db.query.text` values are redacted by the default serializer unless `enhancedDatabaseReporting=true`; `dbStatementSerializer` can replace serialization. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.connection.count` | UpDownCounter | `{connection}` | `db.client.connection.pool.name`, `db.client.connection.state` (`idle`, `used`) | Recorded for MongoDB v4–7 driver server-session acquisition/release and `endSessions` state changes. |
