# MySQL2 instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<SQL operation>` | CLIENT | `db.namespace` (configured database); `server.address` (configured host); `server.port` (configured port, if numeric); `db.system.name="mysql"`; `db.query.text` (query text) | Created for `query` and `execute` calls. Span name is the SQL text before its first space (or full query if none). Query text is formatted with values where possible; `maskStatement` and `maskStatementHook` configure masking. Errors set status to ERROR. `responseHook` runs on successful response and can add attributes. `addSqlCommenterCommentToQueries` adds a comment to non-prepared query text sent to MySQL. |
