# PostgreSQL (`pg`) instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `pg.query:<command> <database>` (or bare `pg.query` when query arguments cannot be normalized) | CLIENT | `db.system.name`, `db.namespace`, `server.address`, `server.port`, `db.query.text`, `db.postgresql.plan`, `db.postgresql.values` | `<command>` is the prepared statement name or normalized SQL command; database suffix is omitted when unavailable. `db.query.text` and `db.postgresql.plan` are conditional on query text and prepared name; `db.postgresql.values` requires `enhancedDatabaseReporting: true` (default false). `requireParentSpan: true` suppresses spans without an active parent; default is false. Query tracing can be disabled with `enabled: false`. |
| `pg.connect` | CLIENT | `db.system.name`, `db.namespace`, `server.address`, `server.port` | Suppressed by `ignoreConnectSpans: true` or `requireParentSpan: true` without an active parent; default for both options is false. |
| `pg-pool.connect` | CLIENT | `db.system.name`, `db.namespace`, `server.address`, `server.port`, `db.postgresql.idle.timeout.millis`, `db.postgresql.max.client` | Requires `pg-pool`; suppressed by `ignoreConnectSpans: true` or `requireParentSpan: true` without an active parent; default for both options is false. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.namespace`, `error.type`, `server.port`, `server.address`, `db.operation.name`, `db.system.name` | Recorded for instrumented query operations that complete through a callback or promise. `error.type` is the error `code`, added only for callback-style queries whose error has a `code`; promise rejections are recorded without `error.type`. |
| `db.client.connection.count` | UpDownCounter | `{connection}` | `db.client.connection.state`, `db.client.connection.pool.name` | Requires `pg-pool`; recorded from pool `connect`/`acquire`/`remove`/`release` listeners. Listeners are installed on the first `pool.connect()` that is not skipped; `requireParentSpan: true` (default false) skips only a connect without an active parent, and once installed the listeners record all later pool events with or without a parent span. |
| `db.client.connection.pending_requests` | UpDownCounter | `{connection}` | `db.client.connection.pool.name` | Requires `pg-pool`; recorded from pool `connect`/`acquire`/`remove`/`release` listeners. Listeners are installed on the first `pool.connect()` that is not skipped; `requireParentSpan: true` (default false) skips only a connect without an active parent, and once installed the listeners record all later pool events with or without a parent span. |
| `db.client.connection.max` | UpDownCounter | `{connection}` | `db.client.connection.pool.name` | Requires `pg-pool`; added on the first `pool.connect()` that is not skipped and subtracted when the pool ends. `requireParentSpan: true` (default false) skips only a connect without an active parent. |
