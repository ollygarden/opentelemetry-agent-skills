# PostgreSQL instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `pg.query:<OPERATION> <database>` | CLIENT | `db.system.name="postgresql"`; `db.namespace`; `server.address`; `server.port`; `db.query.text` (when query text is available); `db.operation.name` (when query text is available); `db.postgresql.values` (when `enhancedDatabaseReporting=true` and values are an array); `db.postgresql.plan` (when a named prepared statement is used); `error.type` (callback errors) | Created by `client.query`; `requireParentSpan=true` suppresses emission without a parent. Query errors record a sanitized exception event and set ERROR status. `requestHook` and `responseHook` may add custom attributes. |
| `pg.connect` | CLIENT | `db.system.name="postgresql"`; `db.namespace`; `server.address`; `server.port` | Created by direct client connection; suppressed by `requireParentSpan=true` without a parent or by `ignoreConnectSpans=true`. Connection errors record a sanitized exception event and set ERROR status. |
| `pg-pool.connect` | CLIENT | `db.system.name="postgresql"`; `db.namespace`; `server.address`; `server.port`; `db.postgresql.idle.timeout.millis`; `db.postgresql.max.client` | Created by pool connection acquisition; suppressed by `requireParentSpan=true` without a parent or by `ignoreConnectSpans=true`. Pool connection errors record a sanitized exception event and set ERROR status. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.namespace`; `server.address`; `server.port`; `db.operation.name`; `db.system.name`; `error.type` (callback errors) | Recorded for instrumented query completions (promise or callback). Queries skipped by `requireParentSpan=true` and synchronous throws do not record it. |
| `db.client.connection.max` | UpDownCounter | `{connection}` | `db.client.connection.pool.name` | Records each pool maximum while the pool is active; removed when the pool ends and replayed if the meter provider changes. |
| `db.client.connection.count` | UpDownCounter | `{connection}` | `db.client.connection.pool.name`; `db.client.connection.state` (`used` or `idle`) | Recorded from `pg-pool` connect/acquire/release/remove events; pool metrics are still enabled when `ignoreConnectSpans=true`, but are suppressed by `requireParentSpan=true` without a parent. |
| `db.client.connection.pending_requests` | UpDownCounter | `{connection}` | `db.client.connection.pool.name` | Recorded alongside pool connection state updates; same gating as `db.client.connection.count`. |
